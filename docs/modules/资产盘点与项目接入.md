## 这个模块是什么(1-2 句)

两件互锁的事:**资产盘点**(运作活②)一个包两种模式——每周模式盘这周变化、首次模式回填老仓历史;**项目接入**把一个仓弄到本机、落一行项目、把名片四字段与群配置写进仓文件(不落库)。历史回填只解释过去,健康灯的判据一条都不读它。

## 代码在哪几层

- **历史回填**:`crates/bw-v4/src/app/backfill.rs:1-6`(模块说明:首次模式,刀5 迁完不写 `.bw/plan`/`.bw/releases.md`,发版改远端 Release、报告挂 ops② issue 评论)、`:8-13`(四条防伪规则:合入按双亲结构判、没标签留空、周目标不倒推、回填不点灯)、`:22`(`MAX_WEEKS=104` 两年上限,扫到就停)、`:25-137`(`backfill_history()` 主流程)、`:46-82`(历史周只统计不写文件)、`:84-110`(历史发版按 git 标签幂等建远端 Release,已存在跳过)、`:126-129`(报告挂 ops② 首次 issue 评论)、`:131-136`(`Event::HistoryBackfilled`)。
- **项目接入/名片/群**:`crates/bw-v4/src/app/project.rs:1-5`(名片正本是 `.bw/PROJECT.md`+`.bw/project.toml`,不落库)、`:15-107`(`create_project()`,先 clone 再建项目行,反过来 clone 失败会留空目录)、`:60-85`(意图落仓文件,仓里已有以它为准、`fill_if_blank` 只补空字段)、`:87-105`(接入完自动建运作活③规范铺底,失败不推翻接入)、`:109-206`(`fetch_repo()` 四种局面如实说清)、`:227-294`(`edit_project_card()` B 类固定标题「编辑项目名片」+worktree+MR)、`:300-398`(`set_project_chat()` B 类固定标题「配置项目群」+worktree+MR+推评审中)、`:213-225`(`remove_project()` 只动库不动仓)。
- **git 现算(回填用)**:`crates/bw-v4/src/git.rs:1-6`(现算不存中间值)、`:611-619`(`first_commit_date()` 回填起点)、`:623-643`(`tags_with_dates()` 标签+提交日期,取提交日期非打标日期)、`:161-241`(`week_stats_many()` 完整周读数,只给回填用)。
- **agent 剧本**:`standard/skills/asset-audit/SKILL.md`(`mode` 参数判 weekly/first;每周盘五类资产、微重构只写建议活草稿、报告挂 ops② 评论;首次模式三层流水线:buddy 算证据→agent 读文本抄→人评审)、`standard/skills/project-handbook/SKILL.md`(给项目写 `AGENTS.md`:先读仓、再问人(沉默=不同意)、才写;buddy 规矩不写进用户仓)。

## 数据落哪

**零本地数据库**。名片四字段落仓文件 `.bw/PROJECT.md`+`.bw/project.toml`(`project.rs:4`);`project` 表只有定位与显示缓存。历史回填**不写仓文件**(刀5 已移除 `.bw/plan`/`.bw/releases.md`)——历史发版在远端建 codehub/GitHub Release(按 git 标签幂等),回填报告挂 ops② 首次 issue 的评论(`backfill.rs:126-129`)。git 读数全是现算(`git.rs:1-6`),一个中间值都不存。

## 依赖什么

内核内:`crate::git`(`is_repo`/`first_commit_date`/`tags_with_dates`/`week_stats_many`)、`crate::isoweek`(周分桶)、`crate::repo::project_file`(ProjectFile/ChatConfig 读写)、`crate::standard`(章程渲染)、`super::{worktree, issue_store}`(worktree 供给、issue 评论)。外部远端:`v4_engine::github`/`v4_engine::codehub`(clone、list/create Release)。

## 产出与验证

- **事件**:`Event::HistoryBackfilled`(weeks+releases+note,`backfill.rs:131`)、`Event::ProjectCreated`(adopted 标记仓里已有名片,`project.rs:94`)、`Event::ProjectCardEditPending`/`ProjectChatChanged`/`IssueSubmitted`。
- **回填防伪读回**:`git log --pretty=format:'%ct %P'` 复算周提交/合入(`git.rs:114-119` 文档给了命令);合入=父提交≥2(双亲结构判,不靠消息文字);无标签如实留空、不倒推版本号。
- **接入如实**:clone 失败不留空项目行(`project.rs:35-37`);非 git 仓目录有东西弹回不硬 clone(`:136-142`);没远端建空目录如实说(`:144-154`)。
- **完成永远由人点**:名片/群配置走轻量活+MR,推到「评审中」停(`project.rs:376-389`);回填只补历史不点灯。

## 没建什么(如实标 defer)

- **资产盘点每周模式的 agent 执行**:剧本在(`asset-audit/SKILL.md`),但定时到点自动建活+自动开工的触发链未在本次代码实现;判据是「本周有没有 ops② issue」(design.md §8.2),非状态表。
- **首次模式三层流水线只实现第一层**(buddy 主机代码算证据+建远端 Release):第二层 agent 读文本抄文档(历史 ops① issue 评论草稿、`.bw/PROJECT.md` 草稿、指标候选)未实现,留给站⑥;第三层人评审。
- **五条探测判据只实现前三条**(提交数/标签/CHANGELOG):远端已关闭 issue、已合并 MR 两条没有对应查询(design.md §4.4,代码只判了否)。
- **防伪规则**:design.md §4.4 列五条,代码 `backfill.rs:8-13` 注释记四条(去掉「远端 MR 数与本地合入数分开报」——因远端信号未实现)。
- **`project-handbook` 写 `AGENTS.md`**:剧本在(`project-handbook/SKILL.md`),实现待首次模式 agent 会话;接入时仓根一个字不写(`project.rs` 无此步)。
- **`progress.rs` 周计划/走势**归模块 16,不在这里。
