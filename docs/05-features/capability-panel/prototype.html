规范

每张活开工时,除了活本身和挂的剧本,Workbench 还按类别塞给 agent 这几份规范 —— 提示词只给「一句话 + 路径」,正文让它按需读。这里只读,改要改 standard/system-prompt/references/;文件不在硬盘就不列,不编路径。

规范写的是什么哪类活会读到状态
metrics怎么写 .bw/metrics.toml、脚本怎么吐数运作活①已派发
week-plan-comment运作活①评论三标题、标签、里程碑;周五每周进展怎么写运作活① · 运作活②已派发
build活的树在哪;评论和标签不是改仓构建 · 优化 · 运维 · 运作活②已派发
bw-assets运作活②对照的 .bw 现行契约(该有 / 整份可删 / 现行格式 / 和①的分工)运作活②已派发
review评审会话要读的那份评审未编进二进制

这一整块是本特性里唯一「新增界面」的部分 —— 工具和技能两块都是把已有的东西重排。要不要进本轮,留给意图 gate 裁。
