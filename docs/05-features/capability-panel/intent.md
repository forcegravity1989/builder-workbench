# Intent · 配置屏收成「能力面板」

> **30 秒导读**:这是什么——把散在配置屏、设置屏、知识库三处的「这台工作台装了什么」收成一处:开工工具、技能与 workflow、注入规范。做法学 Claude 的 Customize 面板与 connectors 文法,但**不引进市场、不引进安装、不引进开关**——BW 的工具靠 PATH 探活、技能靠扫仓目录,这两样都不是「装一次」的东西。给谁看——过意图 / 规格 gate 的人。现在作数吗——**待意图 gate**(2026-09-08 提出)。

**发起人**:产品会话 2026-09-08(看 Codex 插件页与 Claude Customize 面板后提出)。**状态**:待意图 gate。

## 痛点

今天要回答「我这台机器现在能不能开工」,人得开三个屏对照:

1. **工具被劈成两半。** 「这类活用哪个工具」在配置屏,「那个工具在不在」在设置屏。最直接的后果:原型类活的产品默认工具是 Open Design,而本机 Open Design 起不来——今天这两件事写在两个屏上,人不跑到设置屏就不知道原型类根本开不了工。
2. **探活把「没人用它」画成红色。** 六项探活红了四项,而这台机器上真正在用的 claude 和 gh 都在。界面每天自称三分之二坏了,人于是学会不看它——红色一旦不可信,真出事那天也没人信。
3. **红行是死路。** 说完「本机路径里找不到 codehub-cli」就没有下一步了。装它?指个路径?界面一个字都不说,人得去翻文档。
4. **技能表印了两份。** 配置屏一份、知识库资产页签一份,同一个函数渲染两遍。人不知道哪份是正的,改一处忘一处。
5. **开工真正注入 agent 的第三样东西看不见。** 每张活开工会按类别注入几份规范(指标铁律、改仓规则、`.bw` 现行契约),界面上一个字都没有。人不知道自己派出去的 agent 被告知了什么。
6. **设置屏混着两类东西。** 目录 / Orca 地址 / 配色是本机偏好;工具探活是能力接入。Claude 的 Customize 面板把这两类分开,底部才是 Settings——分开是对的。

## 解决方案(体验语言)

配置屏变成这台工作台的**能力面板**,三组:

**① 工具** —— 两块,一块答「用哪个」,一块答「在不在、不在怎么办」。

- 「开工工具」一行一个类别(原型 / 构建 / 优化 / 运营推广 / 运维):选工具的下拉旁边**直接显示那个工具此刻在不在**。配了 Cursor 而 cursor-agent 没装,当场就看见,不用跳屏。
- 「本机工具」一行一个工具:状态、找到的路径或没找到的原话、以及**这一行该怎么修**。红色只留给「有活会用到它、但它不在」;没人用到的写「还没用上」,中性色。

**② 技能与 workflow** —— 全产品唯一一处技能表。知识库资产页签不再重复渲染,改成一句话加一个「去能力面板」的链接。

**③ 注入规范**(待裁决,见开放问题) —— 只读一张表:哪类活开工会注入哪几份规范、每份一句话、文件在哪。人第一次看得见自己派出去的 agent 被告知了什么。

设置屏只留本机偏好(目录 / Orca 地址 / 配色),工具那块整体搬走。

**明确不做**:没有 Discover、没有市场、没有安装按钮、没有每项开关。BW 的技能不是装出来的(自带的编在二进制里,项目自有的扫 `.claude/skills/`),工具不是装在 Workbench 里的(在 PATH 上)。给一个假的开关比不给更糟——真正决定注入什么的是活挂的 workflow,不是这里的一个滑块。

## 飞轮检验(对齐 03)

- **加强哪一截**:「可信所以敢放手」。人一眼知道这台机器现在能干什么、缺什么、缺的怎么补;红色重新变得可信。
- **不把人拽回搬运工**:不引入安装流程、不引入市场浏览。工具还是装在系统里,技能还是放在仓里,面板只负责如实说出来。
- **不破坏铁律**:纯读 + 重排,不碰状态机、不碰现算、不碰「完成由人点」。探活与技能表本来就是现算,没数据仍显示未知,不猜。

## 约束

- **不新增屏**。八屏不变,深链 `BW_PANEL=config` 不变。
- 不做安装 / 开关 / 市场 / Discover。
- 不改内核数据模型:探活(`ToolProbeVm`)与技能表(`skill_list`)都已现算,本次只重排、改着色口径、给红行加修法动作。
- 知识库资产页签删掉重复的技能块,不留兼容双份。

## 开放问题

1. **③ 注入规范要不要进本轮。** 它是唯一一块「新增界面」,前两组都是重排已有的。倾向进——今天人完全看不见派出去的 agent 被告知了什么,这是个真缺口;但它会把本特性从「纯重排」变成「重排 + 新增一块」,请在意图 gate 上裁。
2. **屏名要不要从「配置」改成「能力」。** 倾向不改:深链 `BW_PANEL=config`、文档、旅程都写着配置,改名收益小、波及面大。
3. **设置屏要不要留一行工具摘要**(如「工具 · 6 项,2 项已找到」点进配置屏)。倾向留——没接入任何项目时,顶层仍该看得见本机能力。
