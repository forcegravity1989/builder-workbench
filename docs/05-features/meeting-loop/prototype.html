原型注释：会议、会话和复用边界

发起：项目评审从当前 worktree 的菜单进入，HTML 工件沿用分享工件输入入口；团队版本计划从团队版本计划屏进入。会议工作台负责承接、查看、恢复和回看。

多主机：同一团队的任一成员都可以发起或继续团队会议。会议属于团队，不属于某个主机，不按轮值重复创建。

会中：WeLink 是主要会议视区，会议助手后台读取进度；议题结果进入待确认队列，人可以在间隙开个人会话整理，不会卡住主会。

会后：WeLink 保留正式纪要；人确认的共识和遗留回到原团队、项目或版本上下文，便于下一步跟踪。
