# 通知原型

> 给设计评审者体验 PR 评审通知；行为正本见 [spec](../spec.md)。本目录维护原型入口、源码来源和生成方式，不记录验证流水。产品 UI 或演示场景变化时刷新。

打开 [index.html](index.html)。顶部是原型演示工具，可切换发起/接收主机、发送、模拟检视意见/合入/读取失败及重置。点击通知的 PR 详情只显示「沿用」，正式产品直接打开原生详情。

通知入口、浮层、条目、徽标和发送菜单直接导入 `src/renderer/src/workbench/pr-review-notifications/` 的产品组件；原型只提供模拟数据和操作回调。外壳通过相对路径引用现行版本工作区原型，不复制其脚本、快照或旧总览。顶部工具不属于产品 UI。

在仓根运行 `node docs/05-features/pr-review-notify/prototype/build.cjs` 刷新生成的 JS/CSS。样式从原生样式表生成；不得手改生成物。真实主机投递、权限和 PR 写入须在真壳验证，本原型不提供这些证据。
