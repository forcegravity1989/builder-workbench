# 通知原型

> 给设计评审者体验 PR / MR 与原型评审通知；行为正本见 [spec](../spec.md)。本目录维护原型入口、源码来源和生成方式，不记录验证流水。产品 UI 或演示场景变化时刷新。

打开 [index.html](index.html)。原型沿 `AppWorkspaceShell` 的真实结构展示左侧 Workbench Rail、工作树侧栏、顶部主机切换、会话/浏览器页签和右下评审通知浮窗。**注意：** 其中的原型评审入口（工作树「发送评审」二级菜单、共享页签批注）早于现行设计；现行为在 HTML 预览工具栏点「邀请评审」，评审人在自己的预览批注并「提交给」发起人（见 [spec](../spec.md)），原型待人确认后刷新。原型内容只是弱化的示例快照，重点是壳、入口、主机、页签、通知和批注状态。

发送评审的二级菜单、收件主机选择弹窗和发送动作直接复用 `src/renderer/src/workbench/pr-review-notifications/` 的产品组件；通知浮窗按真实组件的「我发出的评审 / 待我评审」分区，并在本 G1 原型中增加「PR 评审 / 原型评审」事件页签。原型只提供模拟数据和操作回调。外壳通过相对路径引用现行版本工作区原型，不复制其脚本、快照或旧总览。底部“原型注释”不属于产品 UI。

在仓根运行 `node docs/05-features/pr-review-notify/prototype/build.cjs` 刷新生成的 JS/CSS。样式从原生样式表生成；不得手改生成物。真实主机投递、权限和 PR 写入须在真壳验证，本原型不提供这些证据。
