# 通知状态：PR 评审旅程

> 给实现、评审和验收者核对本特性的认可、实现入口与验证结论。行为见 [spec](spec.md)，价值见 [intent](intent.md)。认可或交付状态改变时更新；变更过程、运行证据和问题处理记录留在 PR。

范围已确认：消息通知首期打通 PR 评审，暂不接 WeLink；一键发送给已连接且接入同项目的全部主机。

实现已接入原生工作树菜单、通知浮层和 PR 详情入口；收发通过原生连接 RPC，接收端保存后确认；轮次与事实读回分离。原型直接使用产品通知组件，既有侧栏和 PR 详情沿用各自正本。

静态复检与本机真壳 CDP 已覆盖通知浮层、同项目身份匹配、旧轮次拒收、新周期、无连接时诚实失败、接收后窗口重载与拖拽位置恢复。验证使用本机 RPC 临时请求，不是两台主机投递。独立复验、截图和对应提交见 [PR 478](https://github.com/forcegravity1989/builder-workbench/pull/478)；不将原型演示或远程通用 smoke 等同于完整通知旅程通过。

未验边界：两台真实主机完整评审、跨网络/撤销重配、真实 provider 检视与合入写入、内部 CodeHub 旅程。当前实现仅接 GitHub PR；其他 provider 不宣称已接通。
