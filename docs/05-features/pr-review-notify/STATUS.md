## 当前结论

GitHub PR 与 CodeHub MR 的通知范围、主机多选、首次全选、重发名单、接收持久化、周期隔离、状态读回和本机删除已形成现行规格。G1 原型已扩展同一通知入口的「原型评审」事件：发送只产生通知，进入发起人主机的共享页签后批注按钮可用，提交带成员/主机来源的元素和文字批注，发起人读回后发送给工作模型；首期不跨主机传输截图附件。真实 RemoteBrowserPageToolbar 已接入专用批注 RPC，源主机把批注写入用户数据并由远端定时读回，但 Electron、双机浏览器、远程批注同步、断线重连和 runtime 重启读回仍未验收。浏览器同文档刷新保留批注的 PR #711 已合入；静态测试覆盖同文档 URL、片段变化和本地文件预览刷新。当前没有通知业务 E2E 登记，探索目录测试不能作为通知业务验收证据。
