# Spec · 总览健康看板（#36）

> **30 秒导读**：总览按 [`docs/hifi/overview-36.html`](../../hifi/overview-36.html) 落地。一张图 = 一条滞后 + 0..n 条引领；页签按 `feature`；没写 `leads` 的引领挂到该页签第一条滞后。SDLC 只画现行三条。可点原型就是那份高保真。

上游意图见 [`intent.md`](intent.md)。

## 设计拍板

1. **总览是项目健康看板**，不是 SDLC 地图，不是计划看板。
2. **没有主次版本**。版本 = 远端里程碑。产品忽略 `bw:week:`。ISO 周只做节律。
3. **进度现算**。周五发版或周五盘点才**收口**当周进展评论；进度条在那之前就有数。
4. **`metrics.toml` 两条可选字段**：`feature`（空 = 整体页签）、`leads`（引领盯的滞后 `name`；空 = 该页签第一条滞后）。
5. **图的最小单元**：一条滞后带着 0 到多条引领。同一页签多条滞后 → 图横向排。图上系列行纵向排，勾选显隐（ECharts 同款）。
6. **手填**写在对应滞后那一行，标签就是指标名。
7. **项目指标 · SDLC** 只留：每周提交、每周合入的 PR、未处理 issue。数来自现行 git + 远端采集。不写「距上次发版天数」，不另开「发版记录」（历史版本在版本页签上看）。
8. **粒度**：业务图、SDLC 三张图各自能切周 / 天。没采到的点断开，不补 0。
9. **界面不写无效说明**。设计注释在高保真里标「注释」；壳上不出现。

## 可点原型

[`docs/hifi/overview-36.html`](../../hifi/overview-36.html)（Builder 设计系统 Claude 板，1440×900）。高保真里标「注释」的第二条滞后 / 未写 leads 的引领，只为演示横排和默认挂靠，**不进仓、不进壳**。

## 块顺序

1. 横幅（项目约定未合入 / 开始本版本 / 运作活①进行中）——现行逻辑不动。
2. 第一行：左名片（健康灯在名字旁）| 右北极星。
3. 版本计划与进展。
4. 滞后性指标和引领性指标。
5. 项目指标 · SDLC。

删：独立「发版记录」块；滞后 / 引领两块分卡；健康整栏。

## 操作逻辑

### 名片 + 北极星

- 健康只是名字旁的灯（Unknown / 黄 / 红）。理由不再占一栏。
- 北极星：无读数 → `—` / 目标未设 / Unknown。手填走现行记下命令。
- 编辑名片 / 在研版本下拉 / 拉到最新：现行命令不动。

### 版本计划与进展

- 页签：覆盖当天的在研（带「· 本周」）+ 已发的历史版本（至少 git tag / Release 能读到的）。
- 左：该版本运作活①评论 `## 版本目标` 整段。空着就空着。框高 6 行，多了滚。
- 右：该版本下按周的进展评论（有就最新一条，没有就「还没有周进展」）。框高 6 行，多了滚。
- 下：挂了这个版本的活的五段进度条，只报数。活的列表在计划屏。
- 已发版本没有开放活可读时，进度条空着，不编完成数。

### 滞后 + 引领

**分组**（壳里现算，不写回仓）：

1. 按 `feature` 分页签。空字符串和没写都是「整体」。
2. 每个页签里，每条滞后一张图。
3. 引领按 `leads` 对上滞后的 `name`；空或对不上 → 该页签**第一条**滞后。
4. 只有引领、没有滞后的页签：不另开空图，这些引领仍落到「整体」第一条滞后（没有滞后就不画业务图，只留空态「这一档还没有指标」）。

**一张图**：

- 系列行从上往下：滞后，然后各引领。勾选决定画哪几条。
- 左轴滞后、右轴引领（量纲不同）。滞后可带浅面积。
- 手填只出现在 `collect.kind = manual` 的滞后行：数字框 +「记下」，`aria-label` / 行上已有指标名。
- 周：近 5 个 ISO 周。天：近 14 个日历日。切换只改横坐标和用哪串点，不改分组。

### 项目指标 · SDLC

- 三条，横排，名字左、现值右、下折线。
- 「立即采集」走现行 `CollectRepoStats`。打开项目已自动采的，直接画，不灰「还没采过」除非真的一次都没跑。
- 周 / 天同一套现算。git 提交按窗口分桶；合入 PR / 未处理 issue 走现行远端一趟拉全再按窗口切。失败原话，不写 0。

## 客户会问

- **怎么用？** 打开总览从上往下看。要对比引领和滞后，在同一张图上勾选。手填点滞后那一行的「记下」。
- **不做哪些？** 不在总览列 issue；不把仓统计点灯；不按特性拆业务指标实体（只认 toml 字符串）；不铺 12 条过程指标。
- **和计划屏差在哪？** 总览看健康和进度数字；活的拖拽、发版、出包在计划屏。

## 硬核挑战

- **技术**：多系列 + 双轴 + 周/天是壳上的画法，读数协议不变（A 类现算、B/C 按日流水）。`feature` / `leads` 内核只解析，不迁旧文件。
- **代价**：总览 `mod.rs` 拆出版本卡和指标卡，避免单文件顶满 2000 行。
- **成功**：对着高保真能指认每一块；本仓打开总览能看见滞后 7、引领本周闭环数、SDLC 三条真数；没读数的北极星仍是灰。
