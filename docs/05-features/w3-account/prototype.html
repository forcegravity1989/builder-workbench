已在 Orca 登录窗口打开 W3 门户（专用会话分区）。
本页只表示登录窗口已打开，不代表已登录完成。

只有 W3 账号接口返回 200 且能解析出工号/账号才算登录完成（未登录返回 421，继续等待）；打开窗口 / 加载成功 / Cookie 存在 都不算。

原型注释：官方成功但缺用户资料时，只显示「登录完成（未获取用户资料）」，不显示、不猜测姓名或工号。

登录未完成

未能完成 W3 登录：未配置（URL 非法，请联系管理员）、桥接失败（找不到系统 Chrome / SPES 免密未完成 / 无法读取登录信息）、打开失败 / 超时 / 取消、W3 会话未完成登录（接口 4xx/5xx）或已登录但未读取到有效资料（200 解析失败）。

原型注释：重试即再走一次会话桥接；次按钮为手动登录兜底。登录页/账号接口地址与超时均由 env 配置（`ORCA_W3_LOGIN_URL` / `ORCA_W3_ACCOUNT_API_URL` / `ORCA_W3_LOGIN_TIMEOUT_MS` / `ORCA_W3_SYSTEM_CHROME_PATH`，默认 w3.huawei.com）；URL 非法时不打开空白外网、不猜地址；不需要 OAuth client_id/PKCE。

退出 W3 Account？

关闭登录窗口（若在）、清除 W3 专用会话（partition）全部存储与本地身份；内网站点可能需要重新登录。

仅本机生效，不承诺全局 W3 退出，不影响其它会话。
