范围与边界（据 spec.md / STATUS.md）

  • 把设置里的 Orca Account 页替换为 W3 Account 页，沿用原导航位置与渲染骨架，只改标题、图标语义与页面内容；不新增工具栏入口、不提供分区 / 会话管理 UI。
  • 复用现有 OMDashboard（OMD）W3 后端：一次登录同时得到 OMD 可信身份（/auth/me）与内置浏览器同 session 的会话 Cookie（omd_session）。
  • 仅当 /auth/me 返回 sso_enabled:true 且会话有效才算登录完成；dev 旁路 sso_enabled:false 不计登录完成。
  • 界面只取 display_name / employee_no 两项，token / Cookie 与其它字段不进渲染器、不落日志。

账户状态与登录流程

状态示意 + 会话流程图

登录中 / 失败 / 退出 的小状态（据实现重绘，非交互演示）

登录页已打开
已点登录、打开 W3 页；「等待在 W3 页面完成登录…」，不可重复触发。打开页面不代表已登录完成。
登录未完成（失败）
给出简短原因（未配置 / SSO 未启用 / 不受信来源 / 超时 / 打开失败）+「重试」；不留半成品态。
退出确认
「退出 W3 账户？」确认后退出本账户专用会话，不影响其它会话；失败保持登录态可重试。

已修复问题（代码层，含单测覆盖）

来自实现与 review
✓

generation 迟发请求竞态

所有异步操作绑定 generation + Orca profile id，旧 poller / 迟发响应不能覆盖新状态或劫持新登录。

✓

启动 / profile 恢复

use-w3-account-bootstrap 先经 /auth/me 校验再复用会话，避免用陈旧身份直接恢复。

✓

污染隔离

专用持久 profile 按 profile id 稳定映射（不按 label），internal 隐藏，从不覆盖 remote / ssh / 显式隔离 profile。

✓

open-fail poller

受控轮询 + redirect:'manual' + credentials:'include' + bounded timeout；打开失败 / 超时正确终止轮询并回到失败态。

✓

退出清理

退出清 cookies / storage，并关闭绑定被退役身份的 W3 专用 tabs，避免残留页继续显示已退出身份。

✓

非法 sessionStorage

session store 读取容错：损坏 / 非法状态降级为重建专用 session，绝不以陈旧身份认证。

✓

localization 孤儿命名空间

删除 en / fr / ko 中退役的 auto.components.settings.orcaAccount.* 死文案（27 keys），修复 runtime catalog 门禁。

✓

dev 旁路拒绝

identity 解析要求 sso_enabled === true 且有效 uid；sso_enabled:false 的 dev / mock 返回不计登录完成。
