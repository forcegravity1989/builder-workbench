# Intent · 桌面宠物(desktop-pet)

> **30 秒导读**:这是什么——本次变更的**意图件**:把「活的状态」推给本机的桌面宠物 **Clawd on Desk**——Workbench 不自建宠物,只写一条薄适配:一张活拖进「进行中」它就在跑,到「待评审」它举手告诉你该点了,「阻塞」它出错,手上没活它撤卡。给谁看——过意图 gate 的人。现在作数吗——**in_review**(发起人 2026-09-10 于 [#154](https://github.com/forcegravity1989/builder-workbench/issues/154) 拍板选型;2026-09-24 按 clawd 1.1.0 协议重写制品并实现,随 PR 送评审;状态正本见 [STATUS.md](STATUS.md))。

## 痛点

Super builder 一边在 Workbench 定方向、审结果,一边把大段时间交给 AI 在 Orca 里跑。桌面上那只 Clawd 已经能看见 agent 在想、在敲、在等审批——但它看不见 Workbench 这一层:**哪张活到了待评审等你点、哪张阻塞了、AI 手上还有没有活**。今天这些只能回到 Workbench 主动看侧栏的灯和数字。宠物明明就在桌面上,却对最该告诉你的那件事一无所知。

## 解决方案(体验语言)

装好 Clawd on Desk、在它的「设置 → Agents」里注册一次 Workbench,之后:

- 一张活拖进「进行中」(或点 ▶ 开工)→ 宠物**在跑**;
- 到「待评审」→ 宠物**举手**:该你点了;
- 「阻塞」→ 宠物**出错**;
- 手上没活了 → 宠物**撤卡**,回到它自己的日常。

一个项目在 Clawd 里是一张会话卡,标题写着代表那档的活(「#123 修好登录跳转 · 在跑」)。Workbench 不弹窗、不响、不重试:Clawd 没开就当没这回事。

想换宠物形象:Clawd 自带三套主题,还能把 Codex 的宠物包转成主题;Workbench 设置里一颗按钮,把本机 Codex 已缓存的内置宠物交给它。

## 如何获得

随桌面壳内置;要 Clawd on Desk ≥ 1.0(macOS 可 `brew install --cask clawd-on-desk`,其余平台从它的发布页装安装包)并开着;在它那边注册一次 Workbench(人做)。设置 → Connector 里能看到接没接上、卡在哪一步。先内部试用。

## 飞轮检验(对齐 03)

- **加强哪一截**:「你审结果」的**回来时机**——AI 在受控轨道上跑时人不必盯着,待评审 / 阻塞变成桌面余光可见。不新增 gate、不替人判断。
- **不把人拽回搬运工 / 密审批**:只是把已有状态多投一处;不催办、不打断。
- **不破坏铁律**:推出去的只是标签现算的派生视图,没活就撤卡,不存心情;宠物不改任何状态、不点完成;发不出去静默。

## 约束

- **不自建**:形象、动画、hook 都是 Clawd 的;Workbench 只发它协议里的四个字段加两个可选字段。
- **只认标签正本**:阻塞 > 待评审 > 进行中 > 没活撤卡;不读会话文件、不猜 agent 在想什么。
- **零阻塞**:300ms 超时、失败静默、不重试;起独立任务发,绝不等它。
- **只读它的文件**:运行时文件与 prefs 只读;注册记录在它那边,Workbench 没有写入口——注册必须人做。
- **Codex 宠物包本机复制**:只复制本机 Codex 已缓存的图,不下载、不分发、不覆盖已有。
- **不做**:给 Orca 写 hook;壳内自画;Workbench 主题包;嵌 Clawd 网页端(待真配对地址再判)。

## 影响的用户与系统

单人 Builder(桌面宠物多懂一层);`crates/bw-engine`(`clawd.rs`:运行时文件、id 算法、探活、裸 HTTP、Codex 包导出);`crates/bw`(`app/pet.rs` 现算与报文;`ExportCodexPets` 命令);`app-shell`(桥上 `kick_pet` 两个调用点;Connector 页「Clawd on Desk」一行与详情)。
