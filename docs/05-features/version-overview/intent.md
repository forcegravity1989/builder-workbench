# 版本总览：看清一版的承诺、成果与交付

> 给 Builder、Leader 和设计评审者在判断价值、范围时读。本文定义版本总览为什么做、为谁做及边界；行为与验收见 [spec](spec.md)，认可、实现和验证见 [STATUS](STATUS.md)。价值或范围改变时更新，不记开发流水。

## 用户与问题

Builder 需要知道当前版本为什么做、正在做什么、有哪些成果可以评审。Leader 需要对照当时承诺与实际交付，核对人工验收，而不必先翻遍会话、PR 和归档文件。

版本总览把目标、特性历程与原生成果入口放在同一页，既能看到正式计划，也能找到尚未合入的设计和开发成果。会话结束、PR 合入、用户可用、Issue 关闭和目标达成是不同事实，不能被一个状态替代。

## 目标体验

从 BW 现有“项目 → 版本 → 总览”进入。未计划、版本中和交付后共用“版本基础信息 → 版本目标 → AI workflow 生产力”的结构。每个目标保留名称、负责人、任务数量和原生目标任务入口，人工验收结论原位回显。完整承诺从原有计划／验收导航查看；历史版保留当时材料和结论。

目标内的特性各自展示 Plan / Design / Build / Test / Deploy / Maintain 横向历程。Plan 表示意图收敛，Design 表示 intent、spec 与原型联合评审，Build 包含详细设计、实施 Plan 与开发。计划、设计和实现 PR 的明确合入证据分别提供阶段结束时间；无法识别实现 PR 时才用特性 Issue 关闭兜底。SDLC 的 Plan 与 Build 中的详细实施 Plan 是不同环节。

Test 是开发交付后的验收前区间，目标人工达成且验收 PR 合入才形成首次交付。Deploy 没有实际部署时点时显示未跟踪。后续明确关联版本对同一特性的修理与完善属于 Maintain，从首次交付连续计至后续验收，包含中间等待，不要求恰好两个版本结束。

横轴用浅灰表示已结束、深色表示当前、白底虚线表示后续阶段。已知区间按小时比例呈现，时点精确到分；后续默认长度只帮助理解完整旅程，不代表实际历时或日期承诺。每个阶段直接打开一个明确采集来源，悬停仅显示来源状态；没有来源保持未记录，Deploy 保持未跟踪。原生会话仍从侧栏进入。

特性卡片保留 Issue 标题、负责人、阶段、关联版本与横轴。关联版本是一排版本号标签，悬停或键盘聚焦看一句目标范围，点击进入相应版本核对同一特性。只有明确关联才展示，不凭名称、G1/G2 或日期猜配。

有特性主单或明确引用特性的执行 Issue 时，在目标内分别呈现其历程；其余任务使用同一目标标题行的数量和原生任务入口。一个目标可以包含多个特性和普通任务，无须专设“小需求／bug”目标。

AI workflow 生产力读取本版本目标内 Issue 关联 PR 评论中的六项报告。主要读数为人工介入任务数／本指标有明确结论的任务总数，累计轮次或批次放在右上角；开工额外输入按任务统计，不重复显示次数。返工沿 workflow 的首次人审退回口径。缺报告或覆盖不足保持未知，不把有报告等同于各项都有结论。

版本基础内容与 AI 读数可分别刷新，同范围成功读数可复用；失败保留来源和截至时间并提示错误。只统计人已纳入目标的 Issue，不扫描或代写计划外任务。

## 范围与边界

- 版本总览只读聚合计划、目标、任务、特性与人工验收，复用原有计划、验收、任务、工作树和会话入口。
- 正式承诺、工作草稿、未合入成果与历史验收各有来源。缺证据保持未知，特性阶段不能替人确认目标达成。
- 特性主 Issue 使用“特性”标签，执行 Issue 用明确标题引用保持归属。跨版沿同一个特性身份；G 序号只是版内目标编号。
- 同目标多个特性沿该目标的人工验收结论推导随版交付，不能识别单个特性的例外。计划关联、目标达成和验收 PR 合入缺一时，不补造交付。
- 单版验收和后续维护交付均不表示整个特性完成。反馈、新需求与 bug 继续进入目标关联 Issue。
- 版本按项目实际名称讨论。每个版本只有一次正式人工验收。
- [版本工作区](../version-workspace/spec.md)负责侧栏、工作树归属与版本收尾。事实读取与缓存复用现有能力，不新增业务数据库、平行执行器或会话系统。

## 审阅与成功判据

先看[审阅旅程](journey.html)，再操作[高保真](prototype.html)。原型以 BW 自身固定材料与明确标注的模拟场景呈现，评审说明统一以 `原型注释:` 开头。原型不证明生产读取或运行已经通过。

成功标准是用户能从本版目标定位真实成果、待审项和原生工作入口，分清当前阶段与缺失依据，并在历史版本核对当时人工结论。具体判据见 spec，验证结论见 STATUS 所链接的 PR。

依据：[Issue #334](https://github.com/forcegravity1989/builder-workbench/issues/334)、版本正式计划与用户确认的原型。
