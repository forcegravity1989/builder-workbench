# 版本总览状态

> **维护约定**：给交付、检视和验收者读取。本篇只记录当前六环状态、可追溯入口和未验证边界。用户结果见 [intent](intent.md)，行为与验收见 [spec](spec.md)。运行命令、时间、日志和截图留在对应 PR 验证评论或运行产物，不在这里维护流水账。

## 当前结论

版本总览承接探索 BW 的 W05「用真实效果保持方向」中的进展回看。基础内容显示版本、目标、任务数量、未完成数量和人工验收结论，按项目开启的 SDLC 与 AI 生产力统计沿现有来源读取。项目总览只聚合事实，不替人确认目标达成，也不改变计划、任务或验收材料。

当前实现已覆盖版本材料读取、目标任务入口、阶段与交付事实、历史版本回看、项目级统计开关和失败／未知边界。真实外部来源、完整指标配置链和跨宿主重启读回仍需对应环境核验。

## W05 交叉索引

| W05 步骤 | 版本总览承接 | 协同特性与边界 |
| --- | --- | --- |
| 查看进展 | 查看本版目标、任务、阶段和人工验收结果，并进入原生来源 | 版本计划、版本验收提供材料与人的结论 |
| 查看指标 | 按项目开关后展示总览中的统计区域 | 指标目录、历史采集和读数语义归指标能力 |
| 识别偏差 | 保留未知、失败、缺材料和未完成任务等事实边界 | 指标能力提供读数与完成线，版本验收承接证据核对 |
| 人决定调整 | 提供进入计划、任务和验收的原生入口 | 不自动改 Issue、目标或验收结论 |
| 形成后续计划或任务 | 将下一步交给相应原生入口 | 版本计划和任务管理承接后续动作 |

本特性不按功能项拆分用户旅程。W05 是唯一主用户旅程入口，特性验收点与主旅程可以复用同一条 E2E。

## 未验证边界

- 真实 Electron 中完整 W05 链路及从总览进入计划、任务和验收后的返回上下文。
- GitHub／CodeHub 真实权限、分页、跨宿主读取、项目切换和缓存隔离。
- 指标配置会话、试采、评审合入、计划引用、验收采用和归档后的历史读回。
- 应用独立进程重启后的事实重算，以及失败恢复后不串用其他版本或工作树数据。
- 原型播放、静态检查和 renderer reload 只能支持各自范围，不能替代上述真实证据。
