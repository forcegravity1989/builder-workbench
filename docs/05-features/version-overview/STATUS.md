## 资产归属与边界

本特性从 version-workspace 迁出 #334 的意图、规格、状态、独立 HTML 和可编辑源码，旧位置删除对应正文并改为指针；已有工作区壳原型及其历史验证仍留在原特性。设计系统、壳样式、图标组件和冻结 vendor 继续相对引用，不复制共享正本。

真实数据快照为 `prototype/bw-snapshot.json`，读取范围和时间见其 `source` 与原型“数据来源”。它不读写 BW 宿主登记、不保存产品状态、不自动刷新、不作为持久化提案。历史“已归档”不表示所有目标达成，v0.7 人工结论按原记录展示。

开发使用约定 Git 任务树，内部机器拉同分支经 BW 评审。本机不启动或操控日常 BW；后续真壳验证用隔离开发实例。该长路径工作树的原生依赖构建存在 Windows 路径长度限制，原型预览不依赖 Electron 构建。
