## 未验证与固有限制

- CodeHub 沿显式 MR 链接与原生工作树关联；内部 CLI 的 Issue→MR 反查保留独立未知函数。CodeHub 真机、跨宿主和 legacy SSH 评论读取未验证；没有 owner runtime 的旧 SSH CodeHub 项目不在本机误执行 CLI。
- 生产旧 Pre/Release 分类待统一替换；新首次交付与 Maintain 仍沿正式计划关联、目标人工达成及验收 PR mergedAt。Deploy 暂无采集。两种新呈现未做真实 Electron 验证。同目标多特性仍沿整体结论，无法判断个别例外；未登记临时包不能自动发现。没有替人验收、发布真实包或关闭 Issue。
- 实际开工与独立测试时点没有可靠来源；周期基线是首次计划 PR 所在周的周一09:00，五段为含等待的日历历时，不是人工工时。
- #440 新来源定位、返回视口及未提交草案恢复尚未接入/联调；当前只验证原有项目总览与版本导航往返。#334 可独立验证交付。
- 外部 PR/Issue 站点逐一打开、模型执行、其他项目的 workflow 完整性与用户价值效果没有由页面读数证明。PR #505 原型快照是单任务样例，不是 v0.8 实时汇总；真实汇总只读取当前计划目标内 Issue。
- 网络失败保留旧值、晚返回和跨来源隔离目前有源码与协议检视；尚未在真实 provider 上强制注入网络失败或跨宿主切换，不声称这些交互已真机通过。
