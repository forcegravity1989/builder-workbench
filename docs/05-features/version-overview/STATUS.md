目标人工验收、目标任务入口、计划/验收 PR 时分、六项 workflow 报告及独立刷新保持。指标使用三段读数与对应说明，缺失结论数量收在来源折叠区；小任务使用单份 PR 报告，已删除跨 PR 报告归并，报告不唯一保留未知；报告字段协议与三段数含义不变。浏览不写真实业务材料、不读会话正文、不新增数据库，也不确认目标达成、关闭 Issue 或发布。

## 未验证与固有限制

- CodeHub 继续沿明确 MR 链接及原生工作树关联；内部 CLI Issue→MR 反查能力未知。CodeHub 真机、跨宿主、旧 SSH 评论与模型执行未验证。
- 同目标多个特性沿整体人工结论，不能识别单个特性例外；项目层不把它们合成单一历程。用户调整目标后按新正式计划重读。
- 周一09:00是统计基线，不是真实开工；历时包含等待，不是人工工时或独立测试耗时。未登记临时包无法感知，Deploy 不采集。
- 未替人验收、创建真实发布、关闭 Issue，也未验证完整远端评审到人审合入的链路。
- 真实 provider 强制网络故障、跨宿主切换和项目外 workflow 数据不由当前读数证明；缺失指标保持未知。
