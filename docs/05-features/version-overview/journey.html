同一特性，从设计走向随版交付

周期起点 → 意图确认 → 设计定稿 → 开发交付 → Pre → Release。周期起点取首次包含该特性的计划 PR 合入所在周周一 09:00，延期不重置；计划 PR 合入代表意图确认，不使用纪要确认时间。设计 PR 合入代表 intent、spec、原型联合评审定稿；开发 PR 合入优先，没有可识别开发 PR 时才用特性 Issue 关闭时间兜底，保留来源。

相邻节点形成意图收敛、设计评审、开发、测试与随版准备、试用完善五段日历历时，按小时比例呈现，端点显示日期、时分与时区。周期基线不是实际开工，历时包含等待，不当作人工工时或独立测得的测试耗时。测试、修订可以并行和回返；资料继续通过 PR 或原生会话目录查看。

正式计划包含特性主单或执行单，且对应目标人工验收达成，才按约定推导本版交付：第一次称 Pre，第二次称 Release。未达成不计，缺结论保持未知；同目标有多个特性时暂沿整体结论，不能区分个别交付例外。所有反馈进入目标关联的 Issue，每版仍只有一次正式人工验收。

原型注释: 同一横轴可以对照两条模拟路径：按计划 v1.0 Pre → v1.1 Release；或 v1.0 未交付此特性 → 临时版 v1.0.1 Pre → v1.1 Release。每周一版、两个版本完成是规划默认值，不自动证明交付。示例版本、时间和历时均不改写 BW 真实计划或人工验收。
