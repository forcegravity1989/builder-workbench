同一特性，从设计走向随版交付

Plan 收敛意图：首次计划 PR 合入所在周周一09:00为周期基线，计划 PR 合入代表意图确认。Design 由 intent、spec、原型共同评审，明确设计 PR 合入代表定稿。Build 包含详细设计、实施 Plan 和开发，实现 PR 合入优先，没有可识别实现 PR 才用特性 Issue 关闭时间兜底。SDLC 的 Plan 不等于 Build 中的详细实施 Plan。

Test 从 Build 结束计至验收 PR 合入且目标人工达成，是验收前交付区间。首版称首次交付；后续版本明确纳入同一特性后，Maintain 从首次交付连续计至后续验收，包含再次纳入计划之前的等待。后续版未验收时显示进行中，只计至已标明的观察时点。更多后续版本可以继续产生维护交付，不把第二次交付称为整个特性结束。

Deploy 暂未采集实际部署时间，显示中性“未跟踪”，没有假定半天或已完成区间。验收合入、首次交付和 Maintain 均不能证明已经部署。阶段可以回返；轴上历时含等待，不是人工工时或独立测试工时。采集来源集中列出计划、设计、开发和各关联版本计划／验收 PR，缺记录保持缺口。

正式计划包含特性主单或执行单，目标人工达成决定本版是否计入交付；对应验收 PR／MR 已合入且有 mergedAt 时分才形成交付节点。缺 PR、未合入或缺时间保持未知，不用目标确认、包发布或读取时间补齐。人工结论来源和后续处理仍在目标原位回显，同目标多特性暂沿整体结论，个别例外不能区分。
