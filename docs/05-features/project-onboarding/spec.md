# 项目接入与项目约定（spec · 定义草案）

> **状态**：同 [intent](intent.md)——定义草案，**人确认 = 批准本 PR**。原型：既有特性无独立原型；真实界面以壳与 PR 真壳截图四件套为准（[02 §3.2](../../01-principles/02-working-backwards.md) 原型不进仓口径）。

## 操作逻辑

- **主路径**：启动壳 → 接入屏 → 添加项目 → 选择真实本地路径或输入远端 URL 克隆 → 确认基础信息（名称、路径、远端）→ 写名片 `.bw/project.toml` → 创建「项目约定」Issue → 进入项目面板（总览）。
- **分支**：已有信息先读再确认（CONTEXT 术语口径）；已接入项目再次接入不重复建约定。
- **出错**：路径不存在、远端无权限、克隆失败 → 报错可解释（给原因与下一步）；失败不得留下半份名片冒充接入成功。失败的具体呈现形态以实现为准，本草案给判据。

## 行为要求

1. 使用选定的**真实路径**，不虚构目录或复制假资料。
2. **重复接入不重复建约定**（幂等）。
3. **失败可解释**：路径/远端/权限错误给出原因。
4. 重启后**路径/远端/资料读回一致**（铁律一）。
5. 名片是 `.bw/project.toml` 的展示，不是另一份数据源（CONTEXT 术语）。
