本周可用路径与已知缺口
  • 记分牌能看最近数值、单位和五周走势。悬停柱子可核对周编号与该周值。指标定义在项目配置中，记分牌上没有口径、采集时间或来源详情入口。
  • 无数值保持未知。未配置可能归入通用错误摘要。当前周无点时，主读数仍可能是最近的历史点。缓存的原周区间可保留，记分牌无明确旧快照标记。
  • 记分牌「刷新」重新采集，当前遮罩会挡住总览。页头「更新代码」用于同步主检出和重读来源。采集失败可看现有详情，缺历史脚本可去配置会话。
  • 「配置指标」打开独立的原生会话草稿，由人发送。真实采集、评审采用、多人和重启读回依赖实际环境。本原型使用固定样例。
  • 团队确认行动后可到现有「任务」或「计划」入口。记分牌没有将读数自动带入任务或计划的入口。
