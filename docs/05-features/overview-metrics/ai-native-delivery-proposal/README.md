## 30 秒开始

直接打开 [prototype.html](prototype.html)。无需服务、安装、外部字体或网络，可单独拷贝打开。桌面主目标为 1440 × 900，同时适配 1024 和手机宽度。

原型壳外的辅助条持续标明“设计提案 · 示例数据”，提供三种场景、重置和设计说明。项目、人物、版本、日期、来源编号、运行结果和使用数字均为虚构示例；不包含真实用户结果。

## 一个小版本的故事

虚构内部项目“客户资料导入工具”由 2 位 Builder 开发。10 月想验证的方向是“运营能独立完成资料导入”。本次 v0.3 只解决上传客户表、修正字段映射、定位错误并重试；目标是 3 位运营无 Builder 帮助完成同一任务。

首轮 rc.1 的示例窗口为 10 月 9 日 15:10–15:40：2 位成功、1 位在“手机号码”映射处卡住。运行检查通过、试用入口已分发，与目标用户独立完成是三种不同证据。Builder 决定先修复映射提示，把 AI 建议的“自动标签”移到以后做。

修复后 rc.2 的示例复测窗口为 16:00–16:20：同一组 3 位运营都完成任务。原 2/3 的失败记录保留，复测存在熟悉效应且样本极小，不能推出总体成功率、持续价值或商业收益。证据具备后仍等人确认完成。

## 可以实际操作的路径

1. **总览**：看到月度方向、本次承诺、对象和期限，分别打开运行、分发、使用证据；从唯一主操作处理阻塞。
2. **本次计划**：编辑本次承诺、试用对象和期限，并明确确认；范围内的 3 项任务与成功判据保持可见。点击“移到以后做”显式延期自动标签，不能自动把 AI 建议加入承诺。此稿没有设计通用范围或判据编辑器。
3. **Orca 衔接**：打开“查看本次会话”，查看只读原生工作区快照、带入上下文和执行材料。没有假聊天、假命令、远端 MR 或系统调用。
4. **验收**：按需打开证据抽屉，查看版本、来源、窗口和覆盖对象；不以逐份打开或打勾作为前置门槛。证据不足为 Unknown；2/3 只能记录未达成和下一步。切换修复后场景，匹配的 3/3 复测证据让完成按钮可用；最终仍须在结果确认对话框中明确确认。
5. **指标**：按窗口显示独立完成、成功任务用时、Builder 帮助；首次与复测分别记录，不合成健康分。持续使用、人力节省、商业价值没有数据，保持 Unknown。
6. **同步与重置**：人的未达成决定或完成确认立即同步总览与验收。修改承诺、对象或期限会清除旧完成状态；现有证据只对应原范围，新范围保留 Unknown，不能借原数据确认完成。本演示可重置为匹配的初始场景。场景切换载入该场景初始示例并清除人的确认；重置恢复当前场景，刷新恢复“当前受阻”。状态只在内存中，不写 localStorage、不请求网络、不导出假文件。

## 与已有能力的区别

现行 BW 已有总览指标、版本计划、版本验收和 Orca 原生执行入口，事实源、注入与采集边界以相关特性和 architecture 为准。本提案讨论的是跨屏如何围绕同一个小承诺组织信息、显式延期建议、区分运行/分发/使用证据，并把未达成与下一步交接清楚，不应被读作“这些行为都已实现”。

原生会话、工作树、执行、权限和评审继续由 Orca 提供。原型不新增执行器、业务数据库、真实用户事件采集器、计划事实源、发布系统或审批协议。这里的三类证据视图是讨论模型，并非已批准的数据协议。

## 待确认

- 本次承诺的展示与现有计划事实源如何对应，是否只需改善现有材料衔接即可？
- 运行、分发、真实使用的证据来源是否在实际项目中存在，谁负责收集，如何避免额外记账？
- 证据的来源、版本与窗口是否足够支持人判断，哪些材料可按需查看而不增加审批？
- “未达成 + 下一步”是否能直接复用现有验收与原生会话入口，无需新增工作状态？
- 应把多少信息放总览、多少留在验收材料中？是否可以减少独立屏幕？
- 先用一个真实项目观察能否更快交到用户手中，再决定 UI、模板或 Skill 各承担什么。

本稿不建立月里程碑系统、不要求周五统一门禁，也不把复测 3/3 作为商业价值验收。

## 可编辑来源与构建

- [source.html](source.html)：壳、辅助条、对话框容器。
- [prototype.css](prototype.css)：只定义提案布局，复用唯一设计系统的 tokens 与组件。
- [prototype.js](prototype.js)：内存场景、页面、证据与人的决定。
- [build.mjs](build.mjs)：读取设计系统 styles.css + 本目录 CSS，合为单一内联 style；把本目录 JS 内联，生成可独立复制的 HTML。输出头标注来源与 SHA-256。

在仓根执行：

```text
node docs/05-features/overview-metrics/ai-native-delivery-proposal/build.mjs
node docs/05-features/overview-metrics/ai-native-delivery-proposal/build.mjs --check
```

设计系统文件不在本目录复制维护，不从 CDN 加载。source.html 可在仓内直接打开，单独分发使用生成的 prototype.html。
