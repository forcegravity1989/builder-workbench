# 总览指标 — 六环状态

> 给接手开发、评审和验收的人读取。只记录认可、实现和证据缺口；有真实认可或运行结果时更新。价值见 [intent](intent.md)，行为见 [spec](spec.md)，工程设计见 [design](design.md)。

目标平台为主干 main（原 bw-orca，2026-09-30 扶正）的 Electron/Orca 叠层。本轮指标闭环已实现：业务只支持日／周历史脚本，每次配置新建原生会话，目录同步最新已合入来源，新采集不被旧计划配置锁定，验收可选择新指标。定向测试、真实 Git 与 Node 历史脚本集成、实际组件的替身端口浏览器检查已运行；真实 Electron 与模型完整旅程尚未验证。既有总览与服务证据见 [PR #277](https://github.com/forcegravity1989/builder-workbench/pull/277)和 [PR #272](https://github.com/forcegravity1989/builder-workbench/pull/272)；它们不替代本轮证据。

## 当前实现

- 业务目录、脚本输出与日／周图表收敛为 script + retro=true；不再接受仅当前 value 输出。源数据及历史存储归用户项目或服务所有，BW 不建立每日采集台账。
- “配置指标”使用 MessageSquarePlus 图标；每次在 bw/metrics-refresh 固定树中新建原生会话，加载 SYSTEM、metrics-refresh 及当前目录问题，保留已有未完成改动。
- 目录同步与新采集读取最新已合入定义和脚本；单次执行固定来源修订，材料草稿树不 merge、不重置。同步失败保留原来源并显示错误。
- 验收可从最新目录选择指标补充实测，原计划承诺与 baseline 保留只读；旧配置提交不拦截新采集。证据详情显示来源、采集时间、配置提交与脚本修订；定义指纹保存在材料中，没有专门的口径变化比较或确认界面，不自动判断达成。
- 原型、特性规格、产品 Skill 与协议按同一决定同步；不修改 hifi、共用工作区壳或计划/验收整体布局。项目内建统计仍独立于业务目录，开放 Issue 保留真实当前快照。
- 总览加载与粒度切换先读采集缓存；缓存未命中自动后台补采（非阻塞、仅 not-collected 触发、失败不成环），手动刷新挂全屏阻塞遮罩（PR #292，行为见 spec「采集与可信度」）。
- BW 自身目录落定（PR #292）：北极星删除（未定义清楚不硬立）；4 条指标 = 纳入项目数、每周闭环 issue 数（gh 采集）、使用周一屏项目数（target 6）、计划制定时长（两层采集，target 待真实基线后拍板）。四个脚本已在真实窗口实跑并用 gh/git 独立读回核对（数字见 PR #292）。
