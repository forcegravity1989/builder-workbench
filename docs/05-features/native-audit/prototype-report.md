## 本次探针异常

- **死链残余均为误报**：本仓 1 条来自 `process-hardening/spec.md` 里作为坏例样例的字面路径；dsh 27 条来自文档模板里的占位名（`foo.md`、`source-filename.md`）。两仓真实死链皆为 0；门禁化时需跳过模板目录与行内代码。
- **关键词类读数是弱信号**：数的是「含该模式的文件数」，会把「转述别人的主张」也算进去。定级看那份文件是不是该仓自己的规矩，不看数字大小。
- **C83 本仓判 1 的原因**：秘钥纪律在本仓是用自己的说法写的，通用模式匹不到——这正是方言层存在的理由；跨仓比较仍以通用读数为准，不因此调分。
- **分支保护不可读**：需 API 权限，两仓 C52 均以合并执行人分布替代，分支保护本身记 Unknown。
