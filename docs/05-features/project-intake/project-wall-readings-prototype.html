Builder 02 · 离线
读数三态：有数据给真值 · 读不到给「—」（Unknown 灰字，不装绿、不装零） · 没选过版给「版本未定」。
无健康灯：卡上没有绿/黄/红圆点，墙头没有健康概览条——灯是机器下的结论，判断归人；墙上唯一的状态事实是主机连接（在线/离线/未知）。
口径：版本 = 原生选版偏好 + 主干材料校验（与总览同机制）；承诺进展 = 该版本 data.json tasks × Issue 原生状态与关闭原因现算，决定不做/重复不上卡；在跑会话 = Orca live 口径（fresh 且非 done，与侧栏同源），跨主机经 session tabs 清单链路，离线 ≠ 0；PR 待审 = 该仓全部 open PR 计数。全部杀进程重开可复算一致。
