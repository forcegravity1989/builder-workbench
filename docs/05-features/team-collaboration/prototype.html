团队多人协作

原型注释：项目墙右上角的双人图标是「团队设置」。第一次看可以展开完整操作路线。

完整操作路线

只看权限提示：点「载入双主机样例」，选择安泰工作站「只读」，再点会话栏的「＋」。

  1. 点「从头开始」。韩岚在项目墙右上角点双人图标，输入样例群号 100000000000000001，点「读取团队」。
  2. 给林安填 192.0.2.10，给陈远填 192.0.2.11:6768。点「登记项目」，选星图服务、主负责人林安、参与者陈远。可先查看目录文件，再点「保存到群空间」。
  3. 切到林安或陈远，点「重新打开 BW」。项目墙会显示团队和星图服务。点墙卡的铅笔图标，看到项目类型已是「团队项目」。其他成员连接后默认只读。
  4. 切回韩岚，点墙卡上安泰工作站的「只读 · 待连接」，再点「连接」。会话栏的「＋」会说明这个来源只读。要走评审，从林安桌面打开星图服务，右键工作树「发送评审…」选韩岚；切回韩岚点击右下角评审通知，打开 PR 并提交评审。
  5. 查日志走林安桌面的左下角齿轮 → 远程 Orca 服务器 → 共享此主机。在页面下方按动作、结果、时间筛选，或搜成员、设备、项目和资源。样例可筛选「发送会话输入」＋「已拒绝」。
  6. 可选试整机权限：林安点「生成配对链接」并复制样例链接；陈远在「远程 Orca 服务器 → 连接到主机」点「添加服务器」，粘贴后连接。回到林安的「共享服务器访问」行可撤销。

原型注释：复用位置与演示范围

页头动作沿用 WorkbenchIconButton 和现有 Lucide 图标。团队设置采用同尺寸的 UsersRound 图标，占用项目墙原批量导入主机的位置。

窗口、墙卡右栏、评审入口与远程设置分别对应 AppWorkspaceShell、ProjectSettingsRail、发送评审及远程 Orca 服务器。浅化的是这条旅程周边的原生内容。

样例在浏览器内模拟按群号查群、群空间读写、首次发现、双机与 PR。访问日志拟存于被访问主机的 userData/logs/，按天保存并自动清理，入口在共享服务器访问列表下方。业界参考 GitHub 团队仓库访问。
