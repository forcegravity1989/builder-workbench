原型注释：操作路线
  1. #828：点「查看主机地址」。一键生成时优先使用办公网地址，再保存到群空间。无办公网地址时沿用 Orca 自动选择。可在评审工具切换到「生成失败」，查看失败通知。将「模拟桌面」切到林安，在左下角打开「管理远程主机」，刷新前后对照韩岚同一行的地址。原型参照 PR #850 的 7e0e873747，使用演示数据。真壳、群空间和双机读回待验。
  2. #791：点「查看团队切换」，已绑定的两个 ID 只读，右侧「切换团队」打开新的群名称选择。取消或读取失败保留原团队与草稿；成功后整体切换。刷新按钮悬停或键盘聚焦显示「刷新当前团队目录」。已保存远程主机保留，群空间文件不变。底部不再放「解除绑定」。
  3. #790：「从头开始」。韩岚首次在弹窗里只看到一个「WeLink 群名称」输入框。点击展开群列表，不输入也能翻找已列出的群名；输入时本地同步收窄，前缀命中排在包含命中前。选中「神盾局项目群」后群 ID 与群空间 ID 由 OneBox 自动获取，只读显示在下方，两个 ID 都不再手填；获取完成前提交键禁用。绑定后本机记住这组绑定，重新打开 BW 直接进入团队目录。welink-cli 读取已支持的成员和群主信息，当前桌面的 WeLink 身份用于匹配主机归属，项目目录为空。
  4. #790 失败注入：把「群列表」切到 W3 账户未配置 / 未登录 / 免密未通过时，群名称下方直接显示对应原因和「打开 W3 账户设置」（导航到 w3-account 特性原型，不在本原型复制设置页）；切到限流、连不上、无法解析时只显示原因，不提供跳转。选中「临时对齐（群已解散）」后收起下拉，在群名称下方显示「这个空间没有关联 WeLink 群」。切到「成功但群数超过上限」时列表底部说明搜索仅覆盖已列出的群。
  5. 林安绑定同一个群。项目墙保留当前 BW 的「添加项目」入口，团队设置也提供「登记项目」。登记星图服务后，项目身份写入群空间。
  6. 陈远绑定该群后，BW 根据已登记的 repoId 和各主机项目墙上的实际来源合并成一张现有样式的项目卡。他不需要重复登记星图服务，「交付看板」仍是他的个人项目。
  7. 在团队设置的本机地址栏点击「一键生成并填入」；已有 Orca 配置时按钮变为「一键填入」。群成员随后自动看到地址和连接目标，连接默认保持断开，建立连接后默认只读。
  8. 项目卡保留现有 BW 的主机状态；未连接来源只显示离线状态。需要连接时，从左下角「管理远程主机」进入 Orca 远程服务器设置，建立连接后再回到项目卡查看。
  9. 陈远在自己的 Orca 共享访问列表里，直接用林安行内的「只读 | 完全访问」切换，点击即生效，无需勾选或确认；切回只读随时可用，其他成员不受影响。完全访问后可在该项目下新建会话或新建工作树。访问日志只由被访问主机持有人筛选查看，记下授予与恢复只读，超过 14 天自动清理。

#790 群名称绑定原型已认可。控件形态参照 TeamGroupSpaceCombobox（Popover + cmdk）与 TeamBindingForm 静态表达，未加载 React 组件；失败场景与控件内 failureCopy 一一对应，会议空间过滤与主进程 isMeetingSpaceName 同一条规则，本地排序与 searchTeamGroupSpaces 同一套档位。仍需验证：截断阈值路径、真壳点击流与重启读回。OneBox 免密链路已在 BW 的 W3 分区内真壳复现（2026-11-28，PR #823：隐藏窗口预热让页面 JS 完成 SSO 并种下 WAPCSRFTOKEN，读回 318 个群空间）。演示群名、成员数与群主均为演示数据。

本原型仍沿用 data-theme="light" 与设计系统 styles.css，未切到设计系统现行的 data-skin="ds" data-theme="claude" + workbench-tokens.css 约定；这次不做主题迁移，避免改动已认可的 #791 各屏视觉，配色差异由后续单独处理。

页头动作沿用 WorkbenchIconButton 和现有 Lucide 图标。团队设置采用同尺寸的 UsersRound 图标，放在项目墙原远程主机操作入口的位置。项目卡片复用当前 ProjectWallCard 的布局和操作，不增加团队专用卡片动作。原“批量导入主机”的页头入口改为同位置的 UsersRound“团队设置”入口。

窗口、墙卡右栏、评审入口与远程设置分别对应 AppWorkspaceShell、ProjectSettingsRail、发送评审及远程 Orca 服务器。浅化的是这条旅程周边的原生内容。

样例在浏览器内模拟按群名称查群空间与群 ID、welink-cli 身份匹配、群空间目录同步、成员项目墙按 repoId 聚合、团队主机默认未连接、Orca 同连接只读与完全访问分层和 PR。群空间跳转目标等待实际内网接口提供，不使用虚构地址。团队地址、连接和授权复用 Orca 原生共享主机设置；访问日志只在被访问主机的我分享出去的链接设置中由主机持有人查看，按动作、结果、时间和访问者筛选，存于主机的 userData/logs/orca-shared-host/ 并按 14 天自动清理。原型注释：业界参考 GitHub 团队仓库访问。
