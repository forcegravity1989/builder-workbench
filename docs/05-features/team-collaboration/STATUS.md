# 团队多人协作状态

> 供设计评审、实现与验收者核对当前认可和证据。目标见 [意图](intent.md)，行为见 [规格](spec.md)，阶段和证据边界变化时更新。

- 主单 [#342](https://github.com/forcegravity1989/builder-workbench/issues/342) 已记录群空间承载团队目录、跨主机项目聚合、团队项目默认只读、整机单独授权和宿主留痕方向。
- [旅程原型](prototype.html) 已按当前共识更新：项目卡和未连接状态沿用现有 BW；连接从左下角「管理远程主机」进入；授权页支持选择多个已连接只读设备后一次授予完全访问；日志默认 14 天。
- intent/spec/design 已同步到当前设计；本轮取舍已确认，实现 plan 已在交付记录中完成。当前原型只模拟 WeLink/Orca 行为；真实 WeLink 读写、双机通信、宿主鉴权、日志落盘和重启读回未验。
- 人已确认落地边界：所有 runtime 连接默认只读；旧登记缺少访问级别字段时按只读处理；完全授权只对已建立只读连接的选中设备生效并写回设备登记；日志只记录请求元数据，保留 14 天。
- WeLink 命令核对见 [welink-cli 预研](welink-cli-spike.md)：已知群号可查成员；由登录态枚举全部分组和由群号取群空间信息仍需内网实测。
- 当前 PR 已把团队设置入口、桌面 IPC/preload、`welink-cli im query-group-member` 成员读回和 OneBox `BW/team.json` 读写接入生产代码；本机一个团队：未绑定时同时填写群 ID 和群空间 ID，绑定成功后由本地界面记住并直接打开。团队设置中的主机地址输入和生成入口只更新目录，连接和授权仍复用 Orca 原生设置。
- 尚未用真实群空间和双主机验收：需要内网确认当前登录身份与成员匹配、OneBox 搜索/下载输出形状、群空间文件编辑权限以及生成地址后的两端连接。远端 CI 以 PR 检查结果为准，本机不跑 CI。
