常用链接 交互原型 · 状态栏入口

与 Orca 右下角「端口」入口同构：在底部状态栏放一个图标 + 计数的入口，点开是它自己的 popover 面板，而不是右栏里的子分区、也不是另开的窗口。面板内容照端口面板的范式做：分组头 + 链接行（点击行直接在内置浏览器打开，hover 出复制/编辑/删除），保存网页地址、一键打开。

这是什么 / 为什么这么做

  • 与端口同构：底部状态栏「图标 + 计数」入口 → 点开自己的 popover 面板；位置、尺寸、行结构都与 PortsStatusSegment 一致（人评审意见，2026-11-13）。
  • 不再做：右栏子分区、另开的独立窗口——都已放弃。
  • 只做「端口之外」：本地服务识别与打开已由 Orca 端口面板覆盖，本特性不重复造扫描器。
  • 项目级保存：不同项目存不同链接；重开 Monica 仍在。
  • 克制、隔离：不探活、不自愈、不显示假的“状态灯”，避免退化成泛用书签管理器。

可评审的交互

· 入口：状态栏图标 + 计数；点击开合面板。
· 添加 / 编辑：名称 + 地址；地址须 http/https、不能带账号密码、不能与已有重复。
· 打开：直接点击该行即在内置浏览器打开；hover 出「复制 / 编辑 / 删除」。
· 复制 / 删除：行内图标即时操作。
· 分组：按项目分组，显示当前项目及其链接数。
