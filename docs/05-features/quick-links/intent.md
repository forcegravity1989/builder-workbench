# intent — 项目级常用链接

> **状态：草案，待人 gate。** 本篇维护用户结果、价值、范围、排除和旅程归属。当前行为见 [spec.md](spec.md)，实现落点见 [design.md](design.md)，证据边界见 [STATUS.md](STATUS.md)。[prototype.html](prototype.html) 是交互设计输入，不代表生产能力。
>
> **维护约定**：价值、范围或 gate 结论变化时更新正文，不追加讨论流水或实现清单。

## 用户结果

Builder 在当前项目下可以保存一组常用网页入口，并从 Monica 状态栏直接打开。切换项目时链接彼此隔离，重启后仍能读回。链接只表示可打开的地址，不显示服务健康状态。

## 价值与依据

Orca 端口面板已经覆盖本机监听服务的识别和打开。这个特性补充端口之外的项目级网页入口，减少在全局浏览器书签中查找当前项目资料的往返。来源为 [Issue #650](https://github.com/forcegravity1989/builder-workbench/issues/650)。

目前还没有多个真实 Builder 的使用反馈。项目级归属、是否需要导入已有 web-manager 数据，仍需 gate 时确认。

## 范围

- 在底部状态栏增加与端口入口同构的「常用链接」图标和计数。
- 使用独立 popover 展示当前项目的链接，支持添加、编辑、删除、复制和空态引导。
- 点击链接复用 Monica 内置浏览器打开，修饰键可转系统浏览器。
- 按当前激活仓库隔离并持久化链接，名称和地址是首版字段。

## 排除

- 不重建端口扫描、服务识别、停止进程或浏览器打开通道。
- 不做探活、健康检查、自愈或状态灯。链接没有可推导的服务信号。
- 不做分类树、标签、导入导出或跨项目聚合。
- Explore 旅程归属待 gate 后按特性矩阵确认。

## 目标旅程与判据

候选旅程是 QLJ01「添加并打开项目级常用链接」：在项目 A 添加链接并打开，切到项目 B 看不到该链接，切回项目 A 仍能看到，重启后读回一致。当前仍是草案定义，未登记为 W01–W05 用户旅程 E2E。

Gate 后需要确认以下结果是否成立：

- 项目隔离和重启读回由真实数据推导。
- 合法地址可以打开，非法、重复或含账号密码的地址被拒绝。
- 常用链接面板始终不显示健康或在线状态。
