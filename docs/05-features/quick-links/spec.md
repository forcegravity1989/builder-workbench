## 范围与入口

- **入口**：底部状态栏右端「常用链接」入口（图标 + 条目数），与 Orca 原生「端口」入口并列、同构；点击弹出**自己的 popover 面板**（`side=top`、右对齐、约 24rem 宽），同一时刻只开一个（与端口互斥）。**不塞进右栏子分区，也不另开窗口**（人评审决定，2026-11-13）。
- **对象**：当前激活项目下的网页快捷链接（名称 + 地址）。
- **设计原则**：复用 Orca 现有状态栏入口范式与浏览器打开能力，不新造通道；常用链接区**不探活、无状态灯**，与端口/服务系统完全隔离。
- **原型覆盖**：状态栏「端口」入口（只读同构参照）+「常用链接」入口及其 popover 的打开/收起（含与端口互斥）、面板内增删改、复制、空态、点击打开的提示，以及项目分组说明。原型限制：数据仅内存、刷新即重置；「打开」不真正打开浏览器、只提示。

## 完整用户旅程

**主旅程：添加并打开一个常用链接**

1. Builder 在底部状态栏右端看到「常用链接」入口（图标 + 条目数），点它弹出面板（与端口入口并列同构；点端口入口则切换到端口面板，二者互斥）。
2. 面板头点「添加」，弹出表单：填名称 + 地址。
3. 保存。地址通过校验后新条目出现在列表中；条目数 +1（状态栏入口与面板头同步更新）。
4. 直接点击该行，在 Monica 内置浏览器打开该地址（带修饰键转系统浏览器，与端口行一致）。
5. 切到另一个项目，看到的是那个项目的链接；切回本项目，原链接仍在。杀进程重开后仍能读回。

**分支**：

- **地址非法**：非 http/https、含账号密码、或与已有重复 → 保存被拦，表单内提示具体原因，输入框标红。
- **编辑**：行内「编辑」图标，表单预填当前值；保存同样走校验。
- **删除**：行内「删除」图标，立即从列表移除。
- **复制**：行内「复制」图标，把地址写入剪贴板并提示。
- **面板开合**：点入口展开、再点收起；点面板外区域收起；打开端口面板时自动收起常用链接面板（反之亦然）。
- **空态**：无链接时面板体显示「点添加」引导。

## 行为规则与异常

### 数据与字段

| 字段 | 说明 | 规则 |
|---|---|---|
| 名称 name | 条目主显示 | 必填、去首尾空白、非空 |
| 地址 url | 条目次显示 + 打开目标 | 必填、须为 `http:`/`https:` 绝对 URL，禁止 userinfo（账号密码）；与已有条目去重（尾斜杠归一后比较） |
| id | 稳定标识 | 新建时生成；跨重启稳定 |

排序：按插入顺序（不引入星标/置顶）。

### 交互规则

- **添加/编辑**：同一表单，编辑时预填；保存即写回并刷新列表；**保存/取消后入口面板保持展开**，不被弹窗自动收起。
- **打开**：点击整行即复用内置浏览器打开链；带修饰键（macOS `⇧⌘`、其它 `Shift+Ctrl`）走系统浏览器——与端口行打开口径一致。
- **复制**：把地址写入剪贴板并提示成功。
- **面板开合**：点入口开合、点外部收起；与端口面板互斥，同一时刻只开一个。
- **删除**：即时生效并落盘。

### 异常与边界

- **无状态灯**：常用链接不是服务，不显示任何在线/在线/健康状态；读不到就是没有状态，不制造绿色（铁律二）。
- **持久化失败**：写文件失败时保留内存态并提示失败，不假装已保存。
- **杀进程重开**：链接从持久化读回（铁律一）。
- **空项目/切项目**：按项目隔离，互不串。

## 验收与衡量

验收点（稳定标识，真壳执行；当前仅为定义，未注册）：

| 点 | 场景 | 可观察结果 |
|---|---|---|
| QL01 | 状态栏入口 | 底部状态栏右端出现「常用链接」入口（图标 + 条目数），与端口入口并列同构 |
| QL02 | 空态 | 无链接时面板体显示「点添加」引导 |
| QL03 | 添加合法链接 | 列表新增一条，状态栏与面板头条目数 +1 |
| QL04 | 添加非法地址 | 被拦下并提示原因，输入标红，不写入 |
| QL05 | 添加重复地址 | 被拦下提示重复，不写入 |
| QL06 | 编辑 / 删除 | 修改生效；删除后从列表移除并落盘 |
| QL07 | 复制 | 点复制把地址写入剪贴板并提示 |
| QL08 | 面板开合 | 点入口开合、点外部收起；打开端口面板时本面板自动收起（互斥） |
| QL09 | 打开 | 在内置浏览器打开该地址；修饰键转系统浏览器 |
| QL10 | 项目隔离 | 切项目看到各自链接，互不串 |
| QL11 | 杀进程重开 | 链接读回一致 |

旅程（QLJ01）：点状态栏「常用链接」入口 → 添加一个链接 → 打开成功 → 切项目看不到 → 切回看到 → 杀进程重开仍在。

衡量：intent 判据成立即值得用；运行成绩与证据记 [STATUS](STATUS.md)。

## 取舍与待决问题

**已放弃的选项**：

- *另做一个常驻「服务管理」特性*——首轮误判。Orca 端口面板已覆盖服务识别与打开，重建既重复又与「优先复用」相悖；已删除该方向的 `docs/05-features/services/` 草稿，收敛为本特性。
- *给常用链接加探活/健康灯*——放弃。链接不是服务、无可推导信号，加灯就是假绿（铁律二），且会重蹈 web-manager PRD 警示的「收藏夹病」。
- *右栏子分区 / 新开一级导航 / 独立窗口*——均放弃。2026-11-13 人评审改为**与端口同构的状态栏入口 + popover 面板**：入口形态、面板尺寸与行结构都对齐 `PortsStatusSegment`，与端口入口并列，最贴合「端口之外补一个常用链接」的直觉。
- *星标置顶 / 搜索框 / 分区折叠*——随「与端口同构」一并放弃（端口 popover 无这些）。若后续确有需要再单列确认。

**成本 / 风险**：状态栏入口相关（`StatusBarSurface`、`StatusBarItem` 枚举）属上游 Orca 文件，改动需按 [design.md](design.md) 只做最小挂载 + 枚举登记（Monica 自有组件优先，减少上游冲突面）；项目级持久化**复用既有 `window.api.fs` 桥**读写 `.bw/quick-links.json`，不新增主进程 IPC。

**待决**：见 [intent 待决](intent.md#成功判据与待决问题)——持久化落点与格式、「项目」口径（Monica 项目 vs repoId）、是否导入 web-manager 既有数据。面板交互已按「与端口同构」收敛（无星标/搜索/折叠），如需再加再单列。

## 实现落点建议（非实现设计）

详见 [design.md](design.md)。核心：在 `StatusBarSurface` 与 `PortsStatusSegment` 并列处挂一个 Monica 自有 `QuickLinksStatusSegment`（图标 + 计数 → popover 面板，与端口同构），并在状态栏可见项里登记新的 `StatusBarItem`；打开复用 `createBrowserTab` + 修饰键系统浏览器分支；持久化复用既有 `window.api.fs` 桥读写项目级 `.bw/quick-links.json`。原型 [prototype.html](prototype.html) 为纯前端演示假体。
