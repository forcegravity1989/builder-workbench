# spec — 项目级常用链接

> **状态：草案，待人 gate。** 本篇维护当前入口、行为、失败边界和验收判据。用户结果见 [intent.md](intent.md)，实现落点见 [design.md](design.md)，证据边界见 [STATUS.md](STATUS.md)。[prototype.html](prototype.html) 只用于确认交互，不代表生产行为。
>
> **维护约定**：行为或验收规则变化时更新，不混写历史方案或代码清单。

## 入口与对象

- 入口位于底部状态栏右端，与 Orca 原生端口入口并列。点击后打开独立 popover，两个面板互斥，点击外部收起。
- 对象是当前激活项目的网页快捷链接，字段为名称、地址和稳定 ID。
- 链接按插入顺序显示。地址必须是 `http:` 或 `https:` 绝对 URL，不得包含账号密码，归一化后的地址不得重复。
- 项目切换读取对应项目的链接。持久化失败时保留内存状态并提示失败，不把失败写入显示为已保存。

## 主旅程

1. Builder 打开状态栏的「常用链接」入口。
2. 点击「添加」，填写名称和地址并保存。
3. 地址通过校验后，列表和入口计数同步增加。
4. 点击链接行，在 Monica 内置浏览器打开。使用修饰键时转系统浏览器。
5. 切换项目，链接列表随项目变化。切回原项目或重启后，已保存链接仍可读回。

## 分支行为

- 空列表显示添加引导。
- 非法协议、账号密码或重复地址阻止保存，并在表单中说明原因。
- 编辑复用同一表单并重新校验。删除立即从列表移除并落盘。复制把地址写入剪贴板并提示结果。
- 打开端口面板时常用链接面板收起，反向同样成立。
- 常用链接不执行探活，不显示在线、健康或其他状态灯。

## 验收判据

| 标识 | 场景 | 可观察结果 |
| --- | --- | --- |
| QL01 | 状态栏入口 | 常用链接入口与端口入口并列，显示图标和条目数 |
| QL02 | 空态 | 无链接时显示添加引导 |
| QL03 | 添加合法链接 | 列表新增，入口和面板计数同步增加 |
| QL04 | 添加非法地址 | 保存被拦截，显示原因且不写入 |
| QL05 | 添加重复地址 | 保存被拦截，显示重复提示且不写入 |
| QL06 | 编辑和删除 | 修改、删除结果立即反映并持久化 |
| QL07 | 复制 | 地址进入剪贴板并显示结果提示 |
| QL08 | 面板开合 | 入口开合、外部收起，端口和常用链接面板互斥 |
| QL09 | 打开 | 普通点击打开内置浏览器，修饰键打开系统浏览器 |
| QL10 | 项目隔离 | 不同项目的链接互不串联 |
| QL11 | 重启读回 | 重启后读到与保存一致的链接 |
| QL12 | 状态边界 | 常用链接区不显示健康或在线状态 |

候选用户旅程标识为 QLJ01，覆盖入口、添加、打开、项目切换和重启读回。当前未注册验收点 E2E 或用户旅程 E2E，是否登记留待 gate 决定。

## 原型边界

原型使用内存模拟数据，刷新后重置。「打开」只提示动作，不真正打开浏览器。真实持久化、权限、项目隔离和重启读回应以实现和真壳证据为准。
