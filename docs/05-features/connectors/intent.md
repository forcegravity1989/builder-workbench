## 用户与问题

被管项目的 Builder，要让 Workbench 和它起的执行会话用上外部工具与服务：代码托管（GitHub、GitLab、CodeHub）、任务来源（Linear、Jira），以及 Claude Code / Codex 直接读写的服务（Linear、Notion、Jira、Sentry、Figma 等，在两家工具里叫 connector，底层是 MCP 服务）。在 Orca 里，这些都叫「集成」。

今天卡在三处：

1. **集成卡片只告诉你缺什么，不帮你办。** GitHub / GitLab 没装时只有一个跳官网的按钮；没登录时把 `gh auth login` 这行字摆出来，让人自己去别处开终端跑；CodeHub 没装时只写一句「不在 PATH 上」，装了也不给登录入口。
2. **执行工具的 connector 没有入口。** Orca 唯一相关的是仓库设置里的「MCP Configs」：只读仓库里的四个候选文件，唯一动作是建一份空 `.mcp.json`。实测 Claude Code 与 Codex 真正写配置的位置它一个都不读（详见 spec 依据），终端里装好的在 Workbench 里看不见。
3. **装上不等于能用，界面不说。** 需要登录的服务装上后是未登录，地址错或服务不支持会连不上；Claude Code 与 Codex 还要分别装、分别登。

## 价值与依据

核心收益：在一处（设置 → 集成）把每个外部工具与服务从「缺」办到「通」——装、登录、看真实状态都在原地完成，命令原样可见、由人按回车执行，完成后自动重新检测。

依据：Claude（桌面版 Connectors）和 Codex（`codex mcp add` 后直接走 OAuth）都把「挑一个 → 装上 → 登录 → 看状态」做成原地一条路；Workbench 的执行会话就是这两个 CLI，接入它们自己的配置会话里直接生效，BW 不另存一份。2026-10-10 实测：8 个常用远程服务里 7 个可走 OAuth，GitHub 官方远程服务必须带令牌。价值效果尚无真实 Builder 读回，仍是假设。

## 目标体验

打开设置 → 集成。代码托管卡片上：没装就点「安装 GitHub CLI」，安装命令填进卡片里的终端，按回车装完自动重新检测；没登录就点「登录」，浏览器授权完成后卡片变成已连接。CodeHub 装了就能在卡片上登录、查看登录状态。

同一页下方「执行工具的外部服务」：每行一个服务，写着装在 Claude Code、Codex 哪个上、各自是已连接、要登录、连不上还是未检测。点「添加」从推荐目录挑一个（或填自定义地址 / 命令），选装给哪个工具、所有项目还是仅当前项目，命令预览原样可见；点「安装」后同样在终端按回车执行。已装的行可以登录、移除。

## 范围与边界

- **做**：代码托管卡片（GitHub、GitLab、CodeHub）原地安装与登录；执行工具 connector 的统一列表、推荐目录与自定义添加、按工具拼装命令在内嵌终端执行、登录、移除、从 CLI 读回状态。
- **范围外**：BW 自存清单或令牌；代填密钥、请求头或环境变量；Claude 桌面版 / claude.ai 账号里的 connector；Cursor 等其他执行工具；connector 的启停开关与工具级权限；带令牌的服务进推荐目录；SSH 远端仓库上的安装；卡片状态来自远端 Orca 服务器或 WSL 时的一键安装与登录（终端只在本机桌面运行，保留命令与说明）；Linux 上的 CLI 一键安装（保留安装说明链接）；CodeHub 登录态自动检测（Orca 有意只查 PATH）；Linear / Jira 卡片（已有连接对话框）。
- **相邻**：原生仓库设置里的「MCP Configs」保留不改。被管仓库 `.mcp.json` 是仓库产物，写入后按 PR 评审。

## 成功判据与待决问题

**判据**：Builder 不离开集成页、不手写配置文件，就能把一个代码托管 CLI 从未安装办到已连接，把一个推荐服务装给本机已有的执行工具并看到每个工具上的真实状态；在终端里自己装的同样出现在列表里；杀进程重开后状态从 CLI 重新读回，结果一致；未检测就显示未检测，不显示绿色。

**已裁决（2026-10-10，用户）**：

1. 词表「Connector」**不改窄**：仍是外部工具与服务的统称，Orca 界面上叫「集成」（用户原话：「在 orca 里，connector 就是集成」）。
2. 入口：并进设置 → 集成，不单独开设置页。

**待决（需 gate）**：

3. 推荐目录首版收 8 项（见 spec），都是 2026-10-10 实测在线、Claude Code 识别为可 OAuth 或免登录的官方地址；目录的增删由人定。
4. 「仅当前项目」对 Claude Code 写本机私有的项目节（`-s local`），不写仓库 `.mcp.json`；需要团队共享时由人自己在仓库里提交。Codex 只有全局一级。
5. 原型豁免：02 §3.2 只给非界面改动豁免原型。本特性没有单独原型，实现与文档同批提交，申请以 PR 里的真壳截图作对照；不批则补原型后再合入。
