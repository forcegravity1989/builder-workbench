# Spec · 帮助收成右下角一个能拖的小窗

> **30 秒导读**:帮助只有一个入口(侧栏底部「帮助」),点开是右下角一个能拖的 380px 小窗,三页 —— 主页(本机环境 + 上报入口 + 指南前四章)、指南(搜索 + 全部章节)、上报(标题 + 附加日志 + 发送)。小窗负责**找**,右侧宽抽屉负责**读**。原型 = 三张真壳图 [`shots/after/`](shots/after/)(主页 / 指南 / 上报),深链 `BW_HELP=home|guide|report` 自己起壳也能看。

上游意图见 [`intent.md`](intent.md)。落地状态与验收证据见 [`STATUS.md`](STATUS.md)。

## 设计拍板

1. **一个入口**:侧栏底部一颗「帮助」,和「设置」并排。**不在屏幕边缘贴竖排文字标签** —— 那是网页客服贴片的做法,两个并列还逼人先决定「我要指南还是要上报」。
2. **右下角 + 可拖 + 独立小窗**。帮助窗都在右下;按住深色头能拖到任何地方。**不为了躲右下角的 toast 把它挪到左边** —— toast 罕见且可关,挡住了人自己拖开。
3. **小窗只负责找,抽屉负责读**。一份带自己侧栏的完整产品指南塞不进 380px,所以正文仍在右侧 760px 抽屉里。
4. **状态卡是真数据**。用项目墙那份工具探活(`Vm.env`),**不另开一条探活**。没探过是灰,不是绿。
5. **目录不抄第二份**。章节表从 `docs/03-guide/v4-产品指南.html` 自己的侧栏扫出来(`data-screen="…"` 到 `</svg>` 之后那段文字),指南改了目录不会飘。
6. **一件事只说一遍**。上报页不再像旧弹窗那样把「会附上对照日志」在正文、提示条、勾选说明里各写一遍。

## 界面结构

```
help-panel(fixed 右下,380px,max-height min(660px, 100vh-24px))
├─ help-scroll          ← 深色头和卡片区必须在同一个滚动容器里,
│  ├─ help-hero            负 margin 跨不过滚动容器边界(跨了只会被裁掉顶上一截)
│  │   └─ B 标 / ✕ / 「需要帮手?」/ 一句说明     ← 兼拖动把手
│  └─ help-body
│      └─ 当前页的卡片(第一张挂 help-card-lift,-18px 压在深色头下缘)
└─ help-tabs            ← 主页 / 指南 / 上报,常驻,不随滚动走
```

## 操作逻辑

### 主路径

| # | 人做什么 | 界面 | 背后 |
|---|---|---|---|
| 1 | 点侧栏「帮助」 | 右下角浮出小窗,停在**主页** | `HelpNav = Some(Home)` |
| 2 | 看第一张卡 | 「本机环境就绪」或「n 项工具没找到 + 没找到谁」 | 现算 `Vm.env`,不发命令 |
| 3 | 点「上报问题」行 / 底部「上报」 | 切到**上报页** | `HelpNav = Some(Report)` |
| 4 | 填标题 → 点「发送报告」 | 小窗收起,全屏遮罩转圈 | `ReportWorkbenchIssue` |
| 5 | 成功 | 底栏 toast「问题已上报」 | 遮罩撤 |
| — | 或者第 3 步点某一章 | 小窗**收起**,右侧宽抽屉打开在那一章 | `GuideNav = Some(id)` |

### 分支与边角

- **拖动**:`mousedown` 落在深色头 → 起拖;拖的时候盖一层全屏透明层收 `mousemove` / `mouseup`(指针会跑出小窗,只挂在头上收不到);`mouseup` 或指针离开那层 → 收拖。位移写在小窗的 `transform: translate` 上(是数据不是样式)。**位移只活在这次运行里**,关掉小窗再开还在原地,退出应用就回默认的右下角。**不落盘、不夹持边界** —— 拖动跟着指针,指针被收事件那层限制在窗口内,所以拖不出屏幕。
- **✕ 不是拖**:关闭按钮上单独挡一次 `mousedown` 冒泡,否则按下它会先起一次拖。
- **页签切换不清输入**:`query`(指南搜索)、`title`(上报标题)、`attach_log`(勾选)都挂在小窗组件上,**切页、关窗再开都保留**;只有一次成功发送之后才清空并把勾选复位。
- **指南搜索**:按章节标题大小写不敏感包含匹配;一条都不中显示「没有对得上的章节」,**不显示空列表**。搜索只过滤标题,不搜正文。
- **章节跳转**:抽屉的 `srcdoc` = 指南 HTML + 一行 `window.go("<id>")`(指南自带的换屏函数,它一屏一章不是长滚动)。**只认目录里真有的 id**,认不出就不注入、老老实实开在第一章。
- **抽屉与小窗互不嵌套**:开抽屉必收小窗;抽屉自己有关闭按钮,关了不会把小窗带回来。
- **状态卡只在主页**。指南页和上报页各自的第一张卡去压深色头。

### 出错怎么办

| 情形 | 界面 |
|---|---|
| 标题为空 | 「发送报告」灰着不可点(不弹提示) |
| 本机没有 `bw.log` | 勾选下面直说「本机还没有 bw.log,这次发不出去日志」;**仍可上报**。发送时按「勾了 **且** 文件在」决定要不要附,所以不会出现「日志上传中」转了半天其实什么都没传 |
| 上报失败(远端拒绝 / 没登录 / 不是 git 仓) | 遮罩撤掉,底栏 toast 写**失败原话**(`没做成:<原话>`),**不自动消失**,点「关闭」才走 |
| 探活一条都没有 | 状态卡是灰灯 +「本机环境还没探 / 回项目墙会自动探一遍」,**不画成绿** |
| 指南 HTML 扫不出目录 | 主页那张「产品指南」卡为空、底部「全部 0 章」;抽屉仍能开(从第一章起) |

## 深链

`BW_HELP=home|guide|report` 直开小窗某一页,和 `BW_PANEL` / `BW_VIEW` 同一套。认不出的值**如实打进对照日志**(`未知 BW_HELP=…,忽略`),不静默回退到某一页。

## 不做

- 面板内读指南正文(窄面板读不了带侧栏的完整文档)。
- 指南全文检索(先按章节标题过滤)。
- 消息 / 会话列表那一栏(Claude 有「消息」是因为背后有客服,我们背后是 issue)。
- 缩放、贴边吸附、把拖动位置记到本机文件。
