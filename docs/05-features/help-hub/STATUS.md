## 对着参照改了什么

| 参照(Claude Get help) | 改前(我们) | 改后 |
|---|---|---|
| 一个入口,在侧栏底部菜单里 | 屏幕右缘两条竖排文字标签 | 侧栏底部一颗「帮助」,和「设置」并排 |
| 一张浮层小窗,贴右下 | 760px 全高抽屉 + 居中弹窗,两套 | 一个 380px 独立小窗,贴右下角,**按住深色头能拖** |
| 深色 hero 头,白卡压在下缘 | 没有 | 有(`.help-hero` + `.help-card-lift`) |
| 第一张卡是系统状态 | 状态只在项目墙的环境条上 | 本机环境卡:一颗灯 + 「就绪 / n 项没找到」+ 把没找到的名字念出来 |
| 每条是「图标 + 标题 + 箭头」的可点行 | 上报是一整张表单 | `.help-row`;上报收成 lead + 标题 + 一个勾选 + 一颗主按钮 |
| 底部三个页签 | 没有 | 主页 / 指南 / 上报 |
| 文章列表 | 指南只能从第一章翻 | 目录**从指南 HTML 自己的侧栏扫出来**,点哪章抽屉翻到哪章 |

一件事只说一遍:原来「会附上对照日志」在弹窗正文、提示条、勾选项说明里写了三遍,现在只在勾选项下面写一句,并且分「本机有 bw.log」和「本机还没有」两种实话。
