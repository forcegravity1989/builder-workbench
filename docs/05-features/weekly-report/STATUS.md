## 当前认可与边界

用户已授权本轮界面修订：周报也是项目过程中的管理视图，是提炼信息的地方；以内容为主，固定团队常用模板与配色，版本简化，采用自动渲染、手动兜底。意图与规格已按周期／版本选择、内容更新、补充和导出修订，整篇仍待人审。

模板依据为用户提供的 PT 推理与 AIops 两份 HTML 周报，栏目以用户指定七栏为准，详细列适配 CodeHub 现状。本推理项目采用 PT 的紫色标题／淡紫表头，不混搭 AIops 配色，也不把两份样例描述为完全相同的七栏模板。固定模板规则只在 [规格](spec.md) 定义，原型由单份列定义及同一正文 renderer 呈现主屏与导出。

[MVP demo](prototype.html) 与 [源码](prototype/) 是模拟设计制品，周期、版本、目标、Issue 和人员均为示例；不是已运行的生产周报。真实会话、CodeHub 取数、期间历史／分页、客户支撑、生产文件／Git 留存和共享尚未接线或确认。原型本地状态仅用于交互演示，不证明生产重启恢复或源系统独立读回。

现行周五屏继续服务开发材料准备和核对，周报复用其信息提炼项目情况，不新增开发或验收流程。Issue、目标和人的验收结论仍由原正本承载，周报保存、审阅和导出不构成完成或材料合入证明。

本轮本机浏览器已核对默认七栏展开、固定列数及 PT 紫色／微软雅黑，两个示例周期和简洁版本选择、人工修正保存、选旧版后重新加载、从旧版更新仍采用最新人工内容、跨周期隔离，以及完整 HTML 导出。前周无里程碑定义时显示短空值，验证和风险缺口保持未知。导出与页面同模板／配色，七节直接展开，只包含正文，没有来源 JSON、内部档案编号或代码注释。主屏重新加载及导出 HTML 独立打开的真实浏览器渲染均已核对：人工 125ms 内容保留，固定列数与 PT 紫色、黑边一致，正文不出现人工修正、待核对、原型、示例、取数、来源、归档或会话等操作注释。实际路径和截图随 PR 验证报告；这些模拟检查不证明生产来源或保存已经接线。
