## 当前认可与边界

2026-10-10，用户要求按“自动渲染，手动兜底”撰写 intent 和 MVP demo，明确以单人维护开发、需求与问题汇聚 CodeHub Issue 的项目为主要场景，保留周报完整的项目管理关注点。此要求授权本轮设计制品，意图与规格整篇仍待人审。

原型使用固定示例周期和可切换场景，演示生成、按示例材料组织内容、证据查看、人工补充与显式修正、重新生成后的待核对提示、失败兜底和导出；不连接真实 LLM、CodeHub 或周期调度，不修改生产代码与项目工作状态。真实选周期、自然语言语义冲突识别、部分分页读取和客户／局点支撑尚未接线；显式修正与待核对提示不代表模型已识别内容冲突。源码位于 [prototype/](prototype/)，入口为 [prototype.html](prototype.html)，直接读取共用设计系统样式；本轮新建特性材料，没有替代生产实现或历史方案需要保留。

MVP 源码已建，本轮本机浏览器已验证模拟生成、依据弹窗、验证信息与风险未知态、按材料显示可选节点、人工修正与重生成保留及核对要求、失败保留旧报告、首次失败后的手动目标补充和 HTML 下载。详细检查路径、结果与截图随交付 commit／PR，原型证据不将下表生产验收状态改为通过。
