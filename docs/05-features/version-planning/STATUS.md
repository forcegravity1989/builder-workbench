# 版本计划状态

> 给开发、评审和验收者阅读。本文只记录当前资产状态、已知证据层级和剩余缺口。运行命令、时间、日志和截图留在对应 PR 验证评论或运行产物。价值见 [intent](intent.md)，行为见 [spec](spec.md)，实现见 [design](design.md)。

## 当前结论

版本计划的生产实现已覆盖 G3 计划屏的四区结构、目标编辑、任务投影、批注入口、会议纪要、固定上版来源、会话收折、自动化入口和归档状态。探索 Monica 的 W02 是本特性的唯一主用户旅程入口。

状态表中的“已接入”表示源码或已有检查已覆盖，“部分”表示仍需真实环境或完整用户链路，“待验证”表示没有可用运行证据。

## 用例与资产边界

- W02 的主旅程和验收点复用同一入口：文件、标题、执行项目、真实环境、独立读回和状态按本表登记。只有 W02 无法观察的高风险边界才新增，并需在 [spec](spec.md) 登记观察结果和独立读回。
- 核心 TDD 仅覆盖材料协议、来源映射、CAS 冲突、自动化去重和导航返回等稳定逻辑，位置跟随实现放在 `src/**` 的 `*.test.ts(x)`。普通 UI 变化不新增 TDD。
- 特性验收 E2E 和 W02 用户旅程 E2E 统一位于 `tests/e2e/`，Monica 当前白名单入口是 `tests/e2e/workbench-allowlist.ts`。
- 原型播放和静态检查不计为真实用户证据；新增业务 E2E 仍须经过本特性 spec 的验收边界和 Monica 白名单约束。
