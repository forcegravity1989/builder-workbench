计划屏未开始时显示短卡，只有实际打开本次原生运行会话才进入四区；已有有效材料独立恢复。四区分别为固定来源上版回顾、目标、会议纪要与归档 PR；目标编辑、指标承诺、Feature/Bug 角标、开工与原生详情链沿既有能力。会议纪要取消逐项闭环控件，保留文本、整份人工确认与历史 closed 值。共享启动视图记录仅留渲染进程内，按版本、流程、项目/宿主/owner 与工作树隔离，不成为材料或会话正本。

新建版本通过 selectPriorVersionSource 先定紧邻前版再找验收，初始化把可用来源固定到 summary.progressSource；已有固定来源不自动替换。缺前版显示暂无上版，前版缺验收显示提醒和两行空态；固定读取失败不另设错误卡或重试，不改读其他来源。已有验收未记录 issueMarks 时仍保留 Unknown 与实时 Issue 参考。打开完整验收依据的固定历史导航仍是既有未决边界，不能声称当前入口已实现同源只读整页。

计划与验收使用各自固定工作树和原生自动化。进屏先回显已有数据，不自动同步 Git；“更新代码”是显式同步入口。归档由会话提 PR/MR，状态行从 provider 读回真实状态，读不到保持 Unknown。归档和目标完成是不同事实，完成仍由人确认。

普通新建会话不额外注入 BW Skill；专用入口使用已登记自动化，BW 提示词与 Skill 投影同步、人的时间/模型/复用设置保留。材料修订冲突保留输入，不覆盖另一个会话的更新。没有独立计划确认门槛、贴草稿等待框、全量任务区或第二套会话实现。

此前 G3 的类型检查、lint-staged、原型一致性、ratchet 与 dev profile 真壳结果属于上方历史轮次；#439 本轮没有重跑这些验证。短卡成功/失败、前版缺验收、无目标四区、纪要旧字段保留及跨屏恢复均待真实 Electron 与模型旅程复验。
