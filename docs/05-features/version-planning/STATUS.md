## 当前实现与证据边界

计划屏在同一页展示版本进展、风险与 Top 3 目标。目标直接编辑并自动保存，计划完成/负责人使用紧凑字段；指标从目录添加、按名称防止重复承诺，旧定义明确提示更新，不将仍存在的指标误判为删除。目标卡与验收共用 VersionGoalCard，卡片开合按项目、版本和屏保留。Issue 在目标卡内按 Bug、Feature、未分类展示，详情复用原生入口，拆解由会话按人的选择执行。

版本进展使用明确选定的固定验收来源，可为同版本上周或上一版本。“查看验收依据”定位到相同来源的只读整页，纪要与验收屏共用证据新鲜度计算；读取失败不改读最新材料。已确认且标为“纳入下周计划”的会议指导进入周一候选，由人决定是否进入 Top 3。

计划与验收使用各自固定工作树和原生自动化。进屏先回显已有数据，不自动同步 Git；“更新代码”是显式同步入口。归档由会话提 PR/MR，状态行从 provider 读回真实状态，读不到保持 Unknown。归档和目标完成是不同事实，完成仍由人确认。

普通新建会话不额外注入 BW Skill；专用入口使用已登记自动化，BW 提示词与 Skill 投影同步、人的时间/模型/复用设置保留。材料修订冲突保留输入，不覆盖另一个会话的更新。没有独立计划确认门槛、贴草稿等待框、全量任务区或第二套会话实现。

本轮通过本地材料/指标/报告协议测试、类型与静态检查、生成物一致性检查；原型三个入口通过模拟 DOM 启动。用户明确不运行 CI 和真壳，本地替身及原型证据不能证明实际 Electron 视觉、远端往返、模型遵从或重启体验。
