# 版本计划画布使用指导

> 给试用 [计划画布原型](timeline-prototype.html) 的人读取。只说明画布操作、模板侧栏与配色、取消撤销及演示限制；不收录内网业务明细、真实计划、开发流水或生产承诺。结构为画布含义 → 操作步骤 → 取消与撤销 → 演示限制。只在已实现操作经验证后更新；行为正本见 [spec](spec.md)，证据见 [STATUS](STATUS.md) 及交付 PR。

## 先看画布

这份原型的初始栏目是“GTSLLM版本迭代模板”的示例结构，只参考用户 2026-10-10 提供的最新迭代转测试计划模板的格式。名称、日期和条目均为虚构演示内容，可以自由修改，不代表真实版本或人员安排。

左侧两列分别表示迭代／版本归属和计划栏目。只有月份、日期、星期三行固定；其余是可管理的计划行。初始示例列出各迭代目标、B版本、版本计划，以及质量策划、模型训练团队、设计、开发、测试、资料开发、安全送检、业务联调、适配昇腾及外部转测试等工作方向，可以按自己的计划改名、标记、增删。一条时段行可以有多个独立时段，节点行用于单日节点。

默认使用 GTSLLM 主题：蓝色用于表头，各月份统一浅绿，紫色用于普通侧栏，黄色用于外部依赖侧栏。计划行侧栏的底色和红字／黑字可从右键菜单修改。日期与星期两行按日历把休息日格标浅灰；配置休息日的泳道有极浅遮罩，普通周末只在日期／星期表头标灰，工作日保持白底，浅灰网格用于定位日期，普通时段的深色边界与选中轮廓便于辨认计划。B版本区段与单日节点可选白、橙、黄、灰填充，也可独立选择红字或黑字；这些样式由人选择，不表示自动判定的风险、延期或完成。

在标题区域或画布右键，从“主题”这一排选择 GTSLLM 或 Orca；页头会显示当前主题。Orca 参考原生浅色配色，使用白色画布、浅灰侧栏和深色文字，各月份使用统一的主题配色。切换只改变默认显示颜色，计划名称、日期、手工底色与字色标记、撤销历史均保留；不会换一份模板数据。刷新后恢复 GTSLLM 主题，页面编辑也会按原型限制丢失。

## 调整日期范围

单击页头日期范围，或聚焦后按 Enter；也可右键选择“时间范围”。填写开始日期和结束日期，按原生日期控件的 Tab 顺序移动，Enter 保存。Esc 或把焦点移出编辑器取消。结束不能早于开始，范围不能超过 3660 天；无效输入会显示原因，修改后再保存。

默认范围为 2026-07-01 至 2026-09-30。缩小范围只是隐藏窗外条目，再次扩展仍能看到原安排；跨窗口的时段只显示可见部分，只有真实开始、结束端点出现在窗口内时才能拉伸对应端点。调整范围不改条目日期，也不占用计划撤销步骤；刷新恢复默认范围。

日期处的“休”“班”角标表示本地日历的特殊休息日与工作日，工作日覆盖普通周末。当前本地日历只覆盖 2026 年；未加载、数据无效或未覆盖年份时按普通周末显示，鼠标停在日期处可读到“未配置年度日历，按普通周末显示”。普通周末回退不代表该年度节假日已完整配置。日历只用于日期提示与配置休息日的极浅背景区分，不会替你调整计划，也不改变手工标记。

## 先安排一个时段

1. 找到要安排工作的时段行，在顶部日期行核对起止日期。
2. 在该泳道的空白日期位置按下鼠标，横向拖到结束日期，再松开；也可以从结束日期反向拖回开始日期。
3. 在出现的就地输入框填写名称，按 Enter 保存。按 Esc 取消，不留下新条目。
4. 再在同一泳道的另一处空白位置拖动，可建立第二个独立时段。

每个日期格等宽 40px，各行固定等高 40px，计划行数量可变；按顶部日期选择起止位置。未排期名称在所属侧栏行内横向排列；把鼠标放在这些名称上，滚动鼠标滚轮即可横向查看更多名称，行高保持不变。横向滚动时左侧两列保留，纵向滚动时前三行保留。

## 管理计划行

双击左侧计划行名称，填写后按 Enter 保存，按 Esc 放弃。初始的各迭代目标、B版本和版本计划也可改名或删除；改名保留行的时段或节点类型。

右键要操作的计划行，在“上方新增”或“下方新增”这一排选择时段或节点，再填写行名。时段行通过横向拖动安排日期范围，节点行通过双击空白日期安排单日节点。新行输入时按 Enter 保存；按 Esc、留空或移开焦点取消，不留下空行。

同一右键菜单可用“修改行名称”改名；“底色”横向色块依次为白、橙、黄、灰、蓝、紫，“文字”可选红字或黑字。“删除行”同排显示时段和未排期项的数量；删除会移除整行及其中全部已排期、未排期条目，按 Ctrl+Z（macOS 为 Cmd+Z）可一步恢复。若已删光所有计划行，只剩三个固定表头；在任一固定表头侧栏右键，从“下方新增”选择时段或节点即可重新开始。有计划行时，版本归属的合并区域随行数调整；在该区域右键可新增到末尾。

## 修改和继续编排

下面以初始示例行名说明；改名后的行仍按原有类型操作。键盘习惯参考[微软 Excel 快捷键](https://support.microsoft.com/zh-cn/accessibility/excel/keyboard-shortcuts-in-excel)，本页只实现下面列出的计划画布操作。

单击日期格只选择活动格，不新建条目。方向键逐格移动；Enter／Shift+Enter 下移／上移，Tab／Shift+Tab 右移／左移。Tab 到末日后进入下一行首日，Shift+Tab 从首日进入上一行末日；到表格边界停止。导航会把活动格滚入视野。选中左侧行名时，Enter／Shift+Enter 上下移动行名，Tab 或右箭头进入当前行首日。

按 F2 编辑当前条目，保留原名称并把光标放在末尾；直接输入文字或数字则替换名称。在空白格按 F2 或直接输入，可建立所在日期的单日时段或节点，普通时段之后可以拉伸。编辑时 Enter／Tab 保存并下移／右移，按住 Shift 反向移动；Esc 放弃。已有条目的名称清空后提交会清除整条，新条目留空不保存；行名留空保留原名。

| 想做什么                 | 画布动作                                                                      | 结果                                                              |
| ------------------------ | ----------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 移动时段                 | 拖动时段正文                                                                  | 起止日期一起移动，时长不变                                        |
| 改开始或结束日期         | 拖动时段左端或右端                                                            | 只调整对应日期；单日节点没有拉伸端点                              |

| 安排迭代目标             | 在“各迭代目标”行空白处拖出范围并填写名称；已有目标可双击改名、拖动或拉伸      | 目标按日期范围显示，不自动搬动其他泳道工作                        |

## 取消与撤销

- 拖动中按 Esc：取消本次调整，恢复原安排和此前选择。
- 就地编辑中按 Esc：放弃本次名称修改；新条目不保留。
- 新建计划行填写名称时按 Esc：放弃新行，不留下空行。
- 静止时按 Esc：取消选择。
- 按 Ctrl+Z（macOS 为 Cmd+Z）：撤销上一步已保存的画布修改。
- 按 Ctrl+Y 或 Ctrl+Shift+Z（macOS 使用 Cmd）：重做刚撤销的修改；保存新修改后不再保留原重做分支。
- 清除条目后撤销：恢复整条名称、日期与样式；清除跨多日时段不会只删除其中一天。
- 删除计划行后撤销：整行及其中全部已排期、未排期条目一并恢复。
- 创建、移动、拉伸或成组移动越界，或造成结束早于开始：整次取消，不部分保存。操作中的日期反馈可用来核对候选日期。
- 同泳道已有区段的日期不能重叠，单日节点也不能落在同日；冲突时显示原因并取消整次操作。可以安排多个相邻、不重叠的时段。

在名称输入框中粘贴、Delete／Backspace 和撤销时，使用的是文本编辑行为；先按 Enter／Tab 保存或按 Esc 退出编辑，再操作画布。输入法确认文字时不会提交计划修改。画布上的 Backspace 不清除条目。粘贴清单仍把每行第一列名称放入当前泳道的未排期列表，不填入活动日期格。

## 演示限制

本页只在浏览器内存中演示，不写入项目文件或 Issue，也不调用 Agent。刷新会丢失编辑、恢复默认日期范围；不要把原型当真实计划存档。模板名称只说明初始示例结构，没有模板存储或切换功能。工作簿完整导入、持久化、真实任务关联和执行流尚未接入。显示日期范围与画布内版本名称分别展示，不从模板文件名推定真实版本。
