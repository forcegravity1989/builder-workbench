# 版本计划画布使用指导

> 给试用 [计划画布原型](timeline-prototype.html) 的人读取。只说明画布操作、模板侧栏与配色、取消撤销及演示限制；不收录内网业务明细、真实计划、开发流水或生产承诺。结构为画布含义 → 操作步骤 → 取消与撤销 → 演示限制。只在已实现操作经验证后更新；行为正本见 [spec](spec.md)，证据见 [STATUS](STATUS.md) 及交付 PR。

## 先看画布

这份原型只参考用户 2026-10-10 提供的最新迭代转测试计划模板的格式，使用通用栏目与示例内容。

左侧两列分别表示迭代／版本归属和计划栏目。顶部从月份、日期、星期到各迭代目标、B版本和版本计划；下方按质量策划、模型训练团队、设计、开发、测试、资料开发、安全送检、业务联调、适配昇腾及外部转测试等工作方向安排时间。一条工作泳道可以有多个独立时段。

蓝色用于表头与首个月份，浅绿用于后续月份，紫色用于普通侧栏，黄色用于外部依赖侧栏。只在日期与星期两行把周末格标灰，工作泳道的空白格和普通时段保持白底细线。B版本区段与单日节点可选白、橙、黄、灰填充，也可独立选择红字或黑字；这些样式由人选择，不表示自动判定的风险、延期或完成。

## 先安排一个时段

1. 找到要安排工作的泳道，在顶部日期行核对起止日期。
2. 在该泳道的空白日期位置按下鼠标，横向拖到结束日期，再松开；也可以从结束日期反向拖回开始日期。
3. 在出现的就地输入框填写名称，按 Enter 保存。按 Esc 取消，不留下新条目。
4. 再在同一泳道的另一处空白位置拖动，可建立第二个独立时段。

每个日期格等宽 40px，17 行固定等高 40px；按顶部日期选择起止位置。未排期名称在所属侧栏行内横向排列；把鼠标放在这些名称上，滚动鼠标滚轮即可横向查看更多名称，行高保持不变。横向滚动时左侧两列保留，纵向滚动时前六行保留。

## 修改和继续编排

| 想做什么                 | 画布动作                                                                      | 结果                                                              |
| ------------------------ | ----------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 移动时段                 | 拖动时段正文                                                                  | 起止日期一起移动，时长不变                                        |
| 改开始或结束日期         | 拖动时段左端或右端                                                            | 只调整对应日期；单日节点没有拉伸端点                              |
| 改名称                   | 双击时段或节点，输入后按 Enter                                                | 名称在原位置更新                                                  |
| 安排迭代目标             | 在“各迭代目标”行空白处拖出范围并填写名称；已有目标可双击改名、拖动或拉伸      | 目标按日期范围显示，不自动搬动其他泳道工作                        |
| 改版本归属文字           | 双击左侧版本名称，输入后按 Enter                                              | 只修改这份示例画布内的版本名称                                    |
| 安排B版本区段            | 在“B版本”行空白处拖出范围，填写名称后按 Enter；已有区段可双击改名、拖动或拉伸 | B版本可覆盖多日，不限于单日节点                                   |
| 新增单日节点             | 在“版本计划”行的空白日期格双击，填写名称后按 Enter                            | 节点落在所点日期；拖动节点可改日期                                |
| 改版本区段或节点样式     | 单击选中B版本区段或单日节点，按 1／2／3／4，或右键选样式                      | 分别为白／橙／黄／灰；不改变状态或日期                            |
| 改版本区段或节点文字颜色 | 选中B版本区段或单日节点，按 5，或右键选择“红字 / 黑字”切换                    | 文字颜色与填充分别设置；不改变日期或状态                          |
| 成组移动                 | 先单击一项，再按住 Shift 单击其他项；松开 Shift 后拖动任一已选项              | 所选已排期项一起移动，保持相对间隔                                |
| 先带入名称清单           | 单击左侧所属泳道名称，在画布粘贴一列名称                                      | 每行一个未排期项，列在该泳道左侧；一次最多 100 项，多列只取第一列 |
| 给未排期项安排范围       | 单击左侧未排期名称，再在同泳道的空白日期处横向拖动                            | 该项按拖出的范围排期，不重复新建                                  |
| 给未排期项先选一天       | 从左侧未排期名称直接拖到同泳道日期格                                          | 先安排到该日；普通时段可再拉伸两端                                |
| 取消排期                 | 选中已排期项，按 Delete 或 Backspace                                          | 名称保留在所属泳道左侧的未排期列表；节点和迭代目标也可取消排期    |

## 取消与撤销

- 拖动中按 Esc：取消本次调整，恢复原安排和此前选择。
- 就地编辑中按 Esc：放弃本次名称修改；新条目不保留。
- 静止时按 Esc：取消选择。
- 按 Ctrl+Z（macOS 为 Cmd+Z）：撤销上一步已保存的画布修改。
- 创建、移动、拉伸或成组移动越界，或造成结束早于开始：整次取消，不部分保存。操作中的日期反馈可用来核对候选日期。
- 同泳道已有区段的日期不能重叠，单日节点也不能落在同日；冲突时显示原因并取消整次操作。可以安排多个相邻、不重叠的时段。

在名称输入框中粘贴、删除文字和撤销时，使用的是文本编辑行为；先按 Enter 保存或按 Esc 退出编辑，再操作画布。
