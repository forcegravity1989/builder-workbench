四区验收屏、固定计划身份、人工目标结论、纪要确认、验收证据报告、归档引用和发布状态读回已有生产接线。Bots 的「BW 验收会议助手」模板从同一 Skill 包正源给 bot 安装完整验收 Skill，作为第二入口接线；真实 bot 建会旅程待验。原型是设计输入，协议测试和静态检查不等于 W04 真实主链通过。

## 未验证边界

- 真实模型会话从准备到发布的完整 W04 主链，以及重启后的材料和 provider 独立读回。
- GitHub、CodeHub 和会议工具的真实权限、通知、报告来源、归档和发布结果。
- 跨宿主、SSH/配对、真实部署环境、失败取消重试和脏树冲突。
- 原型播放、模拟数据、静态检查和远端 CI 不能替代以上真实证据。具体运行结论只写入当前 PR 验证评论，并按结论更新本表。
