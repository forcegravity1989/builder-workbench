# 版本验收 — 六环状态

> 给接手开发、评审和验收的人读取。只记录认可、实现和证据缺口；有真实认可或运行结果时更新。价值见 [intent](intent.md)，行为见 [spec](spec.md)，工程设计见 [design](design.md)。

目标平台是主干 main 的 Electron/Orca 叠层。**v10（周五验收会议四步屏）的规格与意图已由负责人于 2026-10-22 逐项确认**，形态正本为 [acceptance-journey-prototype.html](acceptance-journey-prototype.html)。生产实现尚未开始：本篇下方矩阵记录的是 v10 的目标验收点与当前缺口，不是已交付能力。

v9.5（#369/#377）的生产接线仍在 main 上运行，其六环证据与 A01–A14 矩阵随 v10 规格生效而**整体失效**，历史证据从 [PR #369](https://github.com/forcegravity1989/builder-workbench/pull/369)、[PR #377](https://github.com/forcegravity1989/builder-workbench/pull/377) 与 Git 追溯。v9.5 旧稿 [prototype.html](prototype.html) 保留基线身份，不代表现行规格。

## 当前实现与证据边界

main 上运行的仍是 v9.5 形态：单页目标卡三格展开、按轮次呈现与历史周回看、页底会议指导与遗留区块、结论三态下拉、界面派生预览纪要、旅程/出包/归档三类灯、Issue 风险标记、按目标「约定交付」。这些机制在 v10 规格中全部退役，退役与存量材料剥离读回方案见 [design](design.md)。

v10 可直接复用的共用件已随计划屏 G3 生产实现（[PR #399](https://github.com/forcegravity1989/builder-workbench/pull/399)，2026-10-22 合入 main）落地：板面批注组件族（内存态）、会议纪要机制、对象级动作经 Orca 原生发送弹窗递交、上版回顾按固定来源寻址。验收屏尚未接入这些共用件；计划屏侧的批注接入在其 PR 中登记为移交项。

技能正本 `standard/skills/version-acceptance/SKILL.md` 已升到 v0.7.0 并新增验收证据报告模板（2026-10-22，随 #394 分支提交），覆盖四步 SOP、会话驱动板面分工、部署写回、空板硬门禁、纪要两块人工确认、发布知情授权。**该版本尚未按 v10 最终裁定同步**：发布环节要改为「板面只注入、不写材料发布记录」，纪要要补编辑态与撤销语义，演示环境要写明两种形态，跨周与轮次相关表述要清除；技能资产有字节门禁，同步须连同镜像与 manifest 一并再生。

## 连带义务（实现时同批处理，不留缺口）

- **计划屏上版回顾**：其「会议遗留」行现读验收材料的旧会议指导条目；v10 退役会议指导、改由纪要遗留块承载，不同批调整该行会静默变空。
- **总览版本纪要派生**：读取验收材料的结论、目标级交付件、读数与制品登记；退役目标级交付件与新增报告登记后须同批调整。
- **顶层正本**：`docs/architecture.md` 仍把「旅程灯只读 workflow.stage」写成现行能力，`docs/05-features/README.md` 的特性矩阵仍是 v9.5 编号与方向脚注，二者须随第一批生产改动同步。

## 验证纪律

界面与行为改动的交付须附验证报告，本次改动新增或修改的判据内嵌真壳截图四件套（用例名、执行路径、期望结果、截图），截图推永不合入的 `shots/<分支名>` 并钉 SHA。v10 不沿用 v9.5 那轮「不运行 CI 和真壳」的豁免口径——计划屏 G3 生产实现（#399）已按真壳 + 钉 SHA 截图交付，验收屏按同口径执行。叠层单测受执行例数 ratchet 约束，新增须同一交付内对冲删除退役用例。
