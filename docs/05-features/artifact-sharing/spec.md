# 产物分享规格：自管服务上的分享入口

> 给设计、实现、内部评审与验收者读取。本文维护产物分享的入口、配置、数据归属与验收点；价值见 [intent](intent.md)。行为变化时更新对应主题，不追加施工流水。

## 承载与复用

- 浏览器标签工具栏和编辑器页头继续使用既有「Share as artifact」按钮与 Popover，不新增常驻导航或第二套分享入口。
- 分享弹层复用原生 Popover、Button 和状态文案；已分享的链接沿用既有链接面板（复制、在浏览器打开、更新内容）。
- 设置 → Artifacts 保留「Show Artifacts Button」，用「Share server」分节替换 Orca 账号登录；「Allow publishing public artifact links」开关暂留，因为 Artifacts 管理页与 CLI 仍走既有云端路径并依赖它授权，迁移时一并移除。输入、按钮和行内状态复用设置页现有控件。
- 弹层内的公开链接由本机分享记录读回，不请求 Orca 账号状态。

## 配置与数据归属

- 分享服务地址与上传令牌保存在本机 `userData/workbench-share/config.json`，文件权限 0600；地址只接受 http/https，拒绝内嵌凭据、查询参数和锚点，并去掉末尾斜杠。
- 上传令牌只写不读：设置页回显地址和「已保存」，不回显令牌；留空保存表示沿用已存令牌，「Clear token」显式清除。编辑令牌同样只留在主进程，不随发布结果返回渲染进程。
- 每个文件对应的分享记录保存在同目录 `records.json`（0600），按文件来源键索引，记录分享 id、公开链接、编辑令牌和过期/更新时间。编辑令牌只留在本机，用于覆盖内容或删除链接。
- 配置与记录不进入同步设置、Orca 账号或项目仓库；服务端故障不写坏本地文件，读写失败如实返回错误。

## 分享流程

- 弹层每次打开都读取配置：未配置时显示原因、「Open share settings」（直接定位设置 → Artifacts）和重试；配置读取失败时显示重试。设置页保存后重新打开弹层即可生效，无需重启。
- 已配置时按文件来源键查询本机记录。已有链接展示链接面板；没有记录时显示「Generate link」。
- 点击「Generate link」后重新读取当前文件内容，按 10 MiB 上限校验；HTML 原样上传，Markdown 经 `marked` 渲染、`DOMPurify` 清洗为独立 HTML 文档（含标题与基础样式）后上传，文件名扩展名改为 `.html`。
- 有本机记录时用编辑令牌覆盖服务端同一链接；服务端返回 404 说明链接已失效，则删除本地记录并新建链接。
- 上传成功提示「Artifact shared」或「Artifact updated」，链接只在面板中展示，不放进提示消息。
- 服务端未配置、上传令牌被拒、编辑令牌失配、超过上限、限流、服务忙、链接失效、网络不可达等错误码由渲染层映射为可读原因；未知码才回显主进程消息。空文件在上传前拒绝。

## 事实读回与失败

- 分享成功后才写入本机记录；上传失败不改动已有记录，重复分享不会丢失原链接。
- 记录中的链接是本机事实，不宣称服务端一定可访问；打开链接仍由浏览器实际请求决定结果。
- 已保存的令牌不因配置读取失败而清空；地址保存失败时保留原有配置。
- 配置文件或记录文件 JSON 损坏时改名为 `.corrupt-<时间戳>` 留档，随后按空配置/空记录继续，避免一次损坏锁死后续保存与分享。
- 分享服务不可达时，已分享文件的弹层仍显示本机记录的链接，但更新会如实报错。

## 验收点

| #   | 场景 | 期望 |
| --- | --- | --- |
| A01 | 首次使用、未配置服务器 | 弹层说明未配置，可一步进入设置 → Artifacts；保存后重新打开弹层即显示「Generate link」 |
| A02 | 保存地址、留空令牌、再保存 | 地址生效；令牌保持已保存状态，不回显 |
| A03 | 「Test connection」 | 可连时提示成功；不可达或地址非法时行内报错 |
| A04 | 分享 HTML 文件 | 拿到本机记录的链接，公开浏览器可打开 |
| A05 | 分享 Markdown 文件 | 上传的是渲染并清洗后的 HTML，链接内容可读 |
| A06 | 同一文件重复分享 | 覆盖同一链接内容，不产生第二条记录 |
| A07 | 服务端链接被删除后再次分享 | 自动新建链接并替换本机记录 |
| A08 | 令牌错误、超过 10 MiB、服务不可达 | 分别说明原因，不写坏本地记录 |
| A09 | 重启应用 | 已分享文件的弹层仍能读回链接 |
| A10 | Web 或远程客户端 | 设置页显示桌面端修改提示；保存、测试、发布、下线 RPC 在主机端直接拒绝 |

## 旅程

在部署好 `services/bw-share` 的内网机器上填写地址与上传令牌并测试连接；在浏览器打开一个本地 HTML，点「Share as artifact」→「Generate link」，复制链接到另一台机器或非 BW 浏览器打开；修改文件后再次分享，确认同一链接内容更新；重启 BW 后打开弹层读回链接；最后在服务端删除该链接，再次分享确认自动重建。
