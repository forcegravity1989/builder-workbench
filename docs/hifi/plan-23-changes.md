## A. 初始还原(轮1)

把计划屏从源码忠实还原成独立高保真 HTML,类名与 `docs/hifi/index.html` 及 `crates/app-shell/assets/hifi.css` 对齐。

- **A1 三栏布局** — 左 180px 周列表(issue总览/本周/历史周/在研版本)+ 中栏(工具条/周目标/进度条/运作活状态点/七列看板)+ 右 360px 详情抽屉。
- **A2 七列看板** — 待办池/待办/进行中/评审中/已完成/阻塞/已取消,每列带定义,卡片左边框按状态染色。
- **A3 卡片** — 类别 chip、运作活/自动建/未排周徽记、状态灯点、`▶ 开工` 按钮(仅可开工状态)。
- **A4 详情抽屉** — 正文块、状态/类别/工具/workflow/种类/来源/排在/版本/指标/结清/分支、MR 与远端 issue 链接(推得出地址才给)、按状态互斥主操作、阻塞/作废、去会话/蒸馏。
- **A5 可交互** — 点周行切视图(本周 vs issue总览)、点卡片开抽屉、✕ 关抽屉。

## B. 轮2:看板合并与卡面精简(6 条)

- **B1 卡面不显示开工按钮** — 开工入口只留在详情抽屉。`card()` 删除 `kcard-actions`。
- **B2 issue总览加新建活按钮** — 新建的活进待办池(未排期段)。
- **B3 待办池+待办合并为「待办」列** — 一列两段:总览「未排期(上)/已排期(下)」;周视图只「待开始」段(已排期本周),不显示未排期。
- **B4 评审中+阻塞合并为「待处理」** — 上:待评审 / 下:阻塞。
- **B5 已完成+已取消合并为「已完成」** — 上:完成 / 下:拒绝。
- **B6 进行中显示责任人** — 卡片显示开工用户,进行中灯点脉冲(`dot-run`)。`#17` assignee=claude。

## C. 轮3:版本与编辑(4 条)

- **C1 删 issue总览筛选条** — 删掉「类别/版本/来源/关键字」整行。
- **C2 issue总览加「创建版本」按钮+弹窗** — 版本名/说明/勾选未排期 issue 划归;版本=自定义计划包,与发版号(v0.4)不同。`PROJECT.plan_versions`。
- **C3 拖未排期卡到已排期段 → 排期弹窗** — 下拉选「未结束的周计划(本周+未来)」+「已建版本」,确认后变已排期。`dragIssue`/`dropToAssign`/`scheduleModal`。
- **C4 详情双击编辑** — 标题/正文 contenteditable,失焦写回;关闭抽屉自动保存。`editOn`/`editSaveTitle`/`editSaveBody`/`closeDetail`。

## D. 轮4:版本时间与列表视图(2 条)

- **D1 创建版本弹窗加时间行** — 开始/结束两个 date 输入;左栏版本行 hover 显示时间。`v.start`/`v.end`。
- **D2 看板/列表切换** — issue总览与各周右上角加切换按钮(`☷ 切换列表` / `▦ 切换看板`);列表视图一行一活,列=编号/标题/状态/类别/排在/责任人,按合并组顺序。`state.viewMode`/`listView`。

## E. 轮5:详情精简

- **E1 详情抽屉字段精简** — 删:状态/开工工具/workflow/种类/来源/版本(发版号)/推的指标/结清/分支/蒸馏。保留:标题/正文/链接(MR+远端issue合并一行)/类别/排在/操作/去会话;评审中提示保留。

## F. 轮6:详情改居中弹窗

- **F1 详情从右侧抽屉改为屏幕居中弹窗** — 遮罩 + ✕ 关闭;三段式排版:头(状态条 `状态·#num` + 大标题 + ✕)/ 体(正文 + 编辑提示 + meta 两列网格)/ 底(操作按钮 + 去会话)。`detail()` 重写,`render()` 不再挂 grid 第三列。

## G. 轮7:补弹窗基础 CSS

- **G1 补 `.modal-backdrop` / `.modal` 基础规则** — 此前手摘 hifi.css 漏了这两条,导致弹窗退化成块元素堆在页面底部。补 `position:fixed;inset:0` 等。

## H. 轮8:创建版本弹窗样式优化(ui-ux-pro-max)

- **H1 三段式与详情弹窗一致** — 头(小标签「自定义计划包」+ 大标题 + ✕)/ 体(表单)/ 底(浅底条)。
- **H2 版本名必填 `*` 标记** — 陶土色 asterisk。
- **H3 时间双列带小 label** — 开始/结束各一列,各有小字标签。
- **H4 check-list 选中高亮** — 整行暖底 + 文字陶土加粗(`:has(input:checked)`)。
- **H5 helper 文字下移** — 「与发版号不是一回事」从顶部说明挪到底部小字。
- **H6 字段间距加大** — formrow 16px。

## I. 轮9:列 tab、列表筛选、责任人(6 条)

- **I1 「新建活」→「新建issue」** — 总览与每周按钮文案。
- **I2 版本组移到历史周上方** — 左栏顺序:issue总览 → 本周/未来周 → 版本组 → 历史周组 → 在研版本。
- **I3 文案:已分配→已计划、未分配→未计划** — STATUS_META 标签、GROUPS 段标签、排期/创建版本弹窗文案。(注:轮10 又改为「已排期/未排期」。)
- **I4 两段列加子标题 tab** — 待办(未排期/已排期)、待处理(待评审/阻塞)、已完成(完成/拒绝)三列,列头下一行两个子标题按钮,默认只显示第一段卡片,点第二个切到第二段。`state.colSeg`/`setColSeg`/`.kanban-segtabs`/`.seg-tab`。
- **I5 列表「排在」列名→「计划」;状态/责任人列标题可点击筛选** — 点列标题弹浮层(去重值 + 全部),选中过滤,标题显示当前筛选值。`state.listFilter`/`toggleListFilter`/`setListFilter`/`.il-popover`。
- **I6 责任人字段 + codehub 同步** —
  - 新建issue弹窗(标题/正文/类别/**责任人**),创建后进待办池·未排期,toast 提示已同步 codehub。`openNewIssue`/`newIssueModal`/`confirmNewIssue`。
  - 详情 meta-grid 加「责任人」可编辑 input,失焦/关闭保存,改动 toast 提示同步。`editSaveAssignee`。
  - mock 卡片加 assignee:#15/#11 andi、#17 claude、#23 andi。
