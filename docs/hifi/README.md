## 2 · 逐屏(跟壳对齐的口径)

### 项目墙 / 接入

接入只问仓和名片四字段。完成接入会自动建运作活③「规范铺底」:**路径 A,不起 agent**,写入 `.bw/PROJECT.md`、`issue-policy.toml`、`standard.toml`,开 MR 等人合。仓根 `AGENTS.md` 不写。

### 总览

块顺序与壳相同:**名片+健康 → 北极星 → 本周计划进度 → 滞后 → 引领 → 仓指标 → 发版**。没有「负责人」,没有「去计划」(侧栏下一格就是)。「开始本周」只看本周有没有运作活①(含已完成);开着时横幅改「去会话屏」。改名片 = 建一张活提 MR。群号不在总览弹窗里直接写。

### 计划

六列看板 + 周列表。周目标读运作活①那句话(演示里用 `weekPlans` 顶一下)。发版本:**当场在远端建 Release + 打发版标签**,不另建一张发版活。预览·未合入灰着(壳也没接)。蒸馏灰着。

### 会话

终端 / Open Design 标签。蒸馏灰着。Cursor 还没接,选了开不了工。transcript 不再写 `docs/plan/` 或 `connectors.toml`。

### 通知

只有「有 MR 等你合」。按钮是「去看这张活」(落到计划详情),没有「合入并完成」。事件流不编「agent 等你输入 / 蒸馏完成 / 周五自动开工」。

### 配置

四块:开工工具映射 · 技能与 workflow(一张表) · 开工工具探活 + 定时(判据列,没有下次触发) · 规范件(「对一遍账」,没有「规范铺底」按钮)。项目群和在研版本在总览名片里编。Cursor 选项灰着。导入没接。

### 知识库

文档树是 `.bw/` 骨架 + architecture,不再挂 `docs/plan/`、`docs/releases.md`。代码图是 **bw → bw-engine → app-shell**。顶上「对一遍账」,没有升级按钮装成能用。

### 设置

工作区根目录(只影响以后新项目) · 数据目录 · 各工具探活。**没有登录,没有聊天工具登录。** 凭证在钥匙串,群登录是你本机的事。
