## 2 · 逐屏(跟壳对齐的口径)

### 项目墙 / 接入

接入第一步直说「打开本地仓 / 克隆远端仓」,不再用「新建 / 已有」,也不建空目录冒充代码仓;第二步问名片四字段。仓里还没有名片时才建「项目约定」:**路径 A,不起 agent**,只写 `.bw/project.toml` 到常驻树 `bw/project`,工作目录落 `<仓>/.bw/worktrees/project`,开 MR 等人合。已有名片不再开。没合入时总览常驻横幅。不铺 `issue-policy.toml` / `PROJECT.md` / `standard.toml` / `managed.toml`。仓根 `AGENTS.md` 不写。开工工具跟人走本机。

### 总览

目标态稿是 [`overview-36.html`](overview-36.html)(#36),不改本文件里的旧 `renderOverview`。块顺序:**名片(灯在名字旁)+北极星 → 版本计划与进展 → 滞后+引领同图(按 feature 页签) → 项目指标 · SDLC 三条**。没有独立发版记录,没有「去计划」(侧栏下一格就是)。「开始本版本」只看本周有没有运作活①(含已完成);开着时横幅改「去会话屏」。项目约定还没合进默认分支时,顶上另有一条常驻横幅(合入并完成 / 去计划屏)。改名片 / 在研版本 / 项目群 = 同一张「项目约定」,同一棵树,没有单独弹窗。名片上不写规范版本号。


### 计划

四列看板(待办 / 进行中 / 待处理 / 已完成,列内分段)+ 列表视图(预设「开放 / 分配我的 / 我的」+ 计划 / 阶段下拉 + 搜索)。旧左栏删了,改成**右上角下拉**切「全部 issue / 各 `v0.x`」。点卡弹**居中弹窗**:详情 / 新建 issue / 创建版本 / 排期 / Start(定稿 `plan-23.html`)。版本目标读运作活①那一段(演示里用 `weekPlans` 顶一下)。出包:左侧单独一颗,两行进度,不打标签;关着继续跑,按钮三个点再点回来,停止要确认并清中间件。验包不过时行上「详情」列出每条用例和报错。发版本:**当场在远端建 Release + 打发版标签**,号锁死当前版本视图。预览·未合入灰着(壳也没接)。蒸馏灰着。

### 会话

只剩 **Orca** / **Open Design** 两个标签(都走 iframe)。开工入口在计划屏(拖进「进行中」或详情 ▶ Start),不在会话屏——停止 / 开 MR / 推评审 / 删会话在 Orca 里做。Orca 网页地址在**顶层设置**贴(配对 URL,存本机 `settings.toml`,没贴就如实空着、不影响开工)。蒸馏灰着。Cursor 已通(开工走 `create_session`,接回走 `worktree.activate`,不 ensure)。

### 配置

两块:开工工具映射 · 技能与 workflow。探活在项目墙 / 设置;节律在 Orca;规范件对账没有入口。项目群在总览名片里编;在研版本看远端里程碑。Cursor 选项放开(底座已通,探不到如实报错、不退回 Claude)。导入没接。

### 知识库

文档树是 `.bw/` 骨架 + architecture,不再挂 `docs/plan/`、`docs/releases.md`。代码图是 **bw → bw-engine → app-shell**。顶上「对一遍账」,没有升级按钮装成能用。
