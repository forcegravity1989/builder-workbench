## 2 · 逐屏设计记录（历史，未逐项跟随现行壳）

### 项目墙 / 接入

> **2026-09-13 更新**：一体原型里项目墙**不再是一张独立屏**，改成点左栏项目头开出来的覆盖层；两版长相都做了、原型里在墙自己的头上当场切——**弹窗版**（居中 1120px，留着后面的上下文）与**全窗版**（贴满窗口，横向多摊卡）；两版共用同一份内容与搜索框（名字 / 一句话 / 版本号）。下面是历史稿。

接入第一步直说「打开本地仓 / 克隆远端仓」,不再用「新建 / 已有」,也不建空目录冒充代码仓;克隆父文件夹默认显示设置中的工作区根目录,允许改。第二步共用一张基础信息卡,本地或远端已有 `.bw/project.toml` 就带入四字段。仓里还没有名片时才建「项目约定」:**路径 A,不起 agent**,只写 `.bw/project.toml` 到常驻工作树 `bw/project`,工作目录落 `<仓>/.bw/worktrees/project`,开 MR 等人合。已有名片不再开。没合入时总览常驻横幅。不铺 `issue-policy.toml` / `PROJECT.md` / `standard.toml` / `managed.toml`。仓根 `AGENTS.md` 不写。开工工具跟人走本机。

### 总览

目标态稿是 [`overview.html`](overview.html),不改本文件里的旧 `renderOverview`。块顺序:**名片(健康信号在名字旁)+目标方向 → 版本计划与进展 → 滞后+引领同图(按 feature 页签) → 项目指标 · SDLC 三条**。没有独立发版记录,没有「去计划」(侧栏下一格就是)。「开始本版本」只看本周有没有更新指标与版本计划 Issue(含已完成);开着时横幅改「去会话屏」。项目约定还没合进默认分支时,顶上另有一条常驻横幅(合入并完成 / 去计划屏)。改名片 / 在研版本 / 项目群 = 同一张「项目约定」,同一棵树,没有单独弹窗。名片上不写规范版本号。


### 计划

> **2026-09-14 更新**：一体原型里**列表当默认视图**，四列看板退成右上角 `▦` 切过去的副视图。**列表不分组**（按「要我管的在前」平铺：进行中 → 待评审 → 阻塞 → 已排期 → 未排期 → 完成 → 已取消）——状态列的 tag 已经说了一遍。进第一条 issue 之前只留三层：**标题条**（切版本 · 新建 issue · ⋯ · 视图；低频动作都在 ⋯ 里，版本目标降成标题下一行小字）、**筛选条**（一排状态筹码带计数，既是这一版的构成也是筛选开关；竖线前是范围「待完成（默认，藏掉完成 / 已取消）· 全部」，竖线后按状态；右边「谁的活」下拉 + 搜索）、**表头**。原来那七层（目标白框 / 五色进度条 / 演示 tag / 预设条 / 筛选条 / 表头 / 分组头）看 `prototype-v3.html`。下面是历史稿。

四列看板(待办 / 进行中 / 待处理 / 已完成,列内分段)+ 列表视图(预设「开放 / 分配我的 / 我的」+ 计划 / 状态下拉 + 搜索)。旧左栏删了,改成**右上角下拉**切「全部 issue / 各 `v0.x`」。点卡弹**居中弹窗**:详情 / 新建 issue / 创建版本 / 排期 / Start(定稿 [`plan.html`](plan.html))。版本目标读更新指标与版本计划 Issue 那一段(演示里用 `weekPlans` 顶一下)。出包:左侧单独一颗,两行进度,不打标签;关着继续跑,按钮三个点再点回来,停止要确认并清中间件。验包不过时行上「详情」列出每条用例和报错。发版本:**当场在远端建 Release + 打发版标签**,号锁死当前版本视图。预览·未合入灰着(壳也没接)。技能提炼灰着。

### 会话

> **目标态（2026-09-13 更新）**：不再嵌外部 Orca。**没有「会话」导航页签**——进执行面靠左栏 Projects 点树，或计划 ▶开工。执行面中栏页签为 **Terminal / Claude Code / Open Design**（建树序与 Explorer/SC/Diff 对齐 Orca）；顶条只留 Issue 上下文 + 停止/接回。**左栏只有一条**——项目头（整块可点 = 开项目墙）→ 四屏导航（总览 · 计划 · 自动化 · 知识库）→ Projects（始终展开）→ 帮助 / 设置；**视觉（2026-09-14 收口）**：整窗一套 token，一个开关管整窗——`1:1 Orca` 收窄成**结构与交互 1:1，皮肤跟产品**（设计系统是本仓视觉正本，真壳默认也是它）；密度只统一外壳，终端与文件树保留 12px 高密度。反方向（Orca 配色赢、Workbench 屏改读冷灰近黑）也做了一版，可当场切着比。**配置屏没了**：开工工具映射与技能 / workflow 归设置的「能力」一节；**项目墙与设置改成顶层覆盖层**（项目墙两版长相可当场切：弹窗 / 全窗）；**计划屏默认列表**（不分组、状态筹码条，见上面「计划」一节），看板退到 `▦`；**自动化屏进来了**（钟收回本机，铁律不变：完成永远由人点）。决策 [ADR-0006](../02-adr/0006-会话执行内嵌-废弃外部Orca嵌页.md)；可点高保真（本地打开，按原则原型不进 git）：[一体原型 V7 prototype-v7.html](../05-features/native-session-execution/prototype-v7.html)（现行：计划屏自解释，无旅程教练）、[V6](../05-features/native-session-execution/prototype-v6.html)（上一版）、[V4](../05-features/native-session-execution/prototype-v4.html) / [V3](../05-features/native-session-execution/prototype-v3.html)（对照）与 [会话面 prototype.html](../05-features/native-session-execution/prototype.html)（纯 Orca 工作区，当 1:1 对照）。

**历史稿（现行壳仍接近）**：曾只剩 **Orca** / **Open Design** 两个 iframe 标签；Orca 网页地址在顶层设置贴配对 URL。Cursor 已通(开工走 `create_session`,接回走 `worktree.activate`,不 ensure)。

### 配置（目标态已并入设置）

> **2026-09-13 起不再是独立屏**：开工工具映射 · 技能与 workflow 都搬进设置覆盖层的「能力」一节。下面是历史稿。

两块:开工工具映射 · 技能与 workflow。工具检测在项目墙 / 设置;定时任务在 Orca;规范件对账没有入口。项目群在总览名片里编;在研版本看远端里程碑。Cursor 选项放开(底座已通,探不到如实报错、不退回 Claude)。导入没接。

### 自动化（2026-09-13 新增目标态）

一张八列表（名字 · 频率 · 项目 · 下次 · 上次 · 状态 · agent · 操作）+ 工具条（搜索 / 状态筛 / 新建）。新建弹窗里定提示词、agent、项目、工作区（新建 worktree 或挑已有）、频率（每天 / 每周 / 间隔 / cron）、开跑前检查。**钟从 Orca 收回本机**，但只负责开会话：自动创建的 Issue 不许被自动推到完成。

### 知识库

治理站的人读面，三页签对齐 [`home.html`](home.html) 治理三件事：**文档**（按 [`01-document-organization`](../01-principles/01-document-organization.md) 分层：仓根入口 / 原则 / 设计正本 / 特性制品 / `.bw/` 约定；每层标谁维护、怎么变更；不挂 `standard/`——那是设置 · AI Assets；不挂技能、不挂旧 `docs/plan/` / `releases.md`）· **代码**（bw → bw-engine → app-shell + 大文件榜；架构全景 4+1 诚实留白，没数据不装绿）· **对账**（上次资产盘点读回；「现在盘一遍」开会话，只写评论不替改，完成由人点）。没有资产页签，没有升级按钮装成能用。

### 设置

工作区根目录(只影响以后新项目) · 数据目录 · 各工具检测。**目标态**（2026-09-13）：设置改成从左栏底部开的**居中弹窗**，分「本机」（目录 / 外观）与「能力」（Connector · Skills · Category · Plugins · AI Assets）两组；原配置屏两块并入「能力」；**删除「Orca 网页地址」**（见 ADR-0006）。**没有登录,没有聊天工具登录。** 凭证在钥匙串,群登录是你本机的事。
