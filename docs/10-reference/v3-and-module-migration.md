## V3 史实

V3 的六个 crate(bw-core / bw-engine / bw-store / bw-app / ui / app-desktop)于 2026-08-24 删除,全量在 `v3` 分支。当前 Workbench MVP 不是从 V3 迁移来的:底座(`bw-engine`)是拷过来接管后做了三件减法(断掉对 V3 内核的依赖、删只有 V3 用的出口、删两条零调用死链);内核(`bw`)是全新的库与全新的 Command/Event——旧库的二十张表与架在表上的用例整片接不上,改它等于拆了重装还会连累当时还在跑的 V3。两个能力模块(① 关键信息维护、⑤ 桌面壳)对已删 V3 crate 零依赖。名字里的版本号(`bw`、bin 名 `bw-dev`)是共存期的权宜。

能力模块从六个收为五个:①「正本读写」改名「关键信息维护」并扩范围(正本分两类:活态数据正本 + 人持文档正本);②「健康推导」降为 ① 下的二级特性(密封 `DerivedHealth` 守「没数据不装绿」铁律不变,代码不删只降结构层级);原 ③-⑥ 顺位前移为 ②-⑤。
