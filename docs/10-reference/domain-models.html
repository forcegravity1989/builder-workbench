5Domain Model · 领域模型

CONTEXT.md 词表的实体化。聚合根 Project / Issue / Standard;值对象 Signal / Reading;铁律四条。

铁律 1
kill-restart 数字一致 —— 现算推导,重启后读回一致
铁律 2
信号只能从数据推导 —— 没数据=Unknown 不是绿;Derived<Signal> 密封,无 set_signal
铁律 3
完成永远人点 —— agent/定时不得推到 Done;settled_at settle-once 同一活不记两次
铁律 4
定时只建队列不代判断 —— Autopilot 建活 / Collector 采读数,均不自动完成;钟在 Orca
核心边界:本机进化(本地、不上荐)✂️ shared standard(产品方蒸馏、随版本分发)—— 靠反馈站接起,本机做法永不外流。
