会议详情

创建命令 welink-cli meeting create 只有主题、开始、结束、与会人。帮助里没有视频、AI 听、纪要、议题参数。

主题团队计划会
开始毫秒时间戳，示例对应 09:30
结束毫秒时间戳，示例对应 10:15
与会人--meeting-user-list，帮助写的是 W3 ID，可多个
会议主键response.id，数字。议题命令的 --meeting-id 用这个。示例 202674731
enMeetingId32 位。eMeeting 地址用这个。示例 E4F634E7F6D7828CFD6DD9E0E1D3F415
接入建会响应 onlineMeeting.onlineMeetingMsg 里的 Host 链接、Guest 链接、会议 ID

查询详情是 welink-cli meeting info --meeting-id。64 位 ID 不是上面的 32 位 enMeetingId，不能截断后拿去打开纪要。

eMeeting 没有会议室字段。房间只出现在本地记录和群通知正文里。

议题

议题不是建会参数。建会之后用 topic-create 写入，也可以改、删、查。

名称--topic-name
类别帮助中的例子：汇报类、决策类、学习类、研讨类、演示类、审批类
成员--topic-member-list，W3 ID，可多个
议题 ID数字。修改、删除、查材料时用 --topic-id
示例一场会的三条议题
01G2 会议协作进本周 · 决策类
02本周纳入 · 决策类
03上版遗留 · 研讨类

纪要接口读回议题时还有汇报人：roleKey 为 topicReporter 的成员，带姓名和工号。

有 topic-materials 可以按会议 ID 和议题 ID 查材料。材料页面这次没打开，这里不编内容。

AI 听

本机 meeting-minutes 技术参考写：AI 听在 welink-cli meeting create 创建视频会议时默认开启。meeting create --help 里没有这个开关。

会后页面地址：

https://w3.huawei.com/emeeting/#/aiSummary/E4F634E7F6D7828CFD6DD9E0E1D3F415/4

脚本按文字精确点击「语音转文字」，再读 class 名包含 overflow-auto 的容器里的文字，当作转写稿。

示例容器开头：发言人标签和句子。脚本说明发言人标签不能可靠区分多人，页面改版后这套抓取会失效。

页面正文里若出现下面任一提示，脚本认为这场会没有转写稿：

  • 未生成纪要
  • 内容过短
  • 未检测到足够的有效内容

常见原因是没人进入视频会议，或时长太短。

会议纪要

页面地址：

https://w3.huawei.com/emeeting/#/meeting/minutes/E4F634E7F6D7828CFD6DD9E0E1D3F415

本次会议主要内容

会议级正文。写入时不带 topicId。

议题 · G2 会议协作进本周

每个议题一块正文，写入时带该议题的 topicId 和 HTML。

读：GET /emeeting/server/api/meeting/v1/getMeetingSummryText/{enMeetingId}

写：POST /emeeting/server/api/meeting/v1/addMeetingSummryText，saveHistory 为 false。脚本注释写这是草稿，不产生历史版本。读回的是转义后的 HTML，写入要送原始 HTML。

脚本不调用这个按钮。meeting-minutes 写明由人在这个页面上点击「发送纪要」。
