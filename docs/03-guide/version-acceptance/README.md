# 核对本版成果与遗留

> 给准备验收和评审本版交付的 Builder 使用。验收入口或读回方式变化时，同步本页与[引导矩阵](../../04-design-system/guidance.md#探索-monica-矩阵)。

从左下角「帮助 → 探索 Monica → 工作旅程 → 验收成果」播放「周末书集」样例。验收和版本总览的页头问号可重播各自的操作引导。

1. 展开侧栏的本版，点「验收」，也可以从本版总览点「版本验收」。尚未开始时，点「开始验收」，在预填的会话中补充要求后发送。
2. 在「验收准备」打开已生成的证据报告，或用「聚合」请助手准备报告。到 Showcase 展开目标，看本版计划的验收标准，对照报告、演示或原任务证据逐项核对。需要将意见交给助手时，从页头开启「批注模式」，在目标、验收标准或 Issue 旁记录。
3. 由人在目标行选择「未判定」「达成」或「不达成」。缺证据时可先保留未判定。未达目标可填写「下一步」，开放 Issue 可以标记遗留并加备注。
4. 在「会议纪要」编辑或请助手整理共识和遗留。核对遗留的落实结果或跟进 Issue 后，点「标记人工确认」。确认后的正文只读。要修改时先撤销确认，编辑后再确认。

页头显示「已保存」时，可重新打开同版验收读回结论和纪要。保存失败时，展开详情或点「重试保存」。只有已提交且可读的本版固定计划才能提供目标。若目标仍为空，先核对计划来源，再从验收页头点「更新代码」。未配置会议或出包时，仍可核对计划、报告和人工结论。

要归档，点「发起归档」把请求交给验收助手。队友从原生 PR/MR 页面核对材料并评审合入。更新项目代码后，在「版本总览」点「刷新来源」，核对材料阶段、归档状态与人工结论。下版「计划准备」沿固定前版来源显示延期和会议遗留，由人决定是否纳入下版。版本总览基础读数无需开启统计。

Windows Electron 隔离项目已核对入口、固定计划、人工结论、纪要确认和材料读回。实际助手生成报告、托管平台归档和多人读回的覆盖见[验收状态](../../05-features/version-acceptance/STATUS.md)。
