# 观看构建交付旅程

> 给初次用 BW 执行和检视任务的团队成员。本文维护已核对的探索入口和样例操作。演示入口或步骤变化时同步本页与[引导矩阵](../../04-design-system/guidance.md#探索-bw-矩阵)。

打开左下角「帮助 → 探索 BW → 工作旅程 → 构建交付」。空项目也能播放。直接点击步骤可以看一段，点「顺序播放」从当前步骤开始，播放中可以暂停和继续，点「重播」回到项目墙。

样例「周末书集」有两条任务。预约任务由作者和评审者交接，地点说明在独立工作区并行。看原型时留意浏览器工具栏里的「注释页面元素」、原型上的批注编号和面板里的「发送」。已有改动的任务可直接选择「验证并准备 PR」。还可以从「评审通知与共享主机」查看选接收主机的入口。

看最后一幕时先读 PR 的合入结果，再看负责人确认完成、关闭样例议题后，墙卡从 0/2 变为 1/2。墙卡统计本版已关闭的议题，版本总览的目标任务展示未完成数。目标达成结果由版本验收记录。

## 在工作区里跟做

- **批注原型。** 从工作区的标签菜单打开「新浏览器选项卡」，载入原型。浏览器工具栏右侧的问号可重播。点「注释页面元素」，选中页面控件，写下具体意见并点「添加」。通过编号和批注栏回看，折叠后可以再展开。空白页先在地址栏载入网页。未发送的批注需在当前打开的页面处理。Windows 重启样例恢复了页面地址，批注栏已清空。
- **反馈 BW 自身问题。** 在 BW 界面按 `Ctrl+Alt+B`（macOS `⌘⌥B`）唤起批注，可在「设置 → 快捷键」搜索「批注」并调整。保存批注后，点批注浮窗旁的纸飞机。浮动工作区会准备草稿，先显示批注、再附起手提示；检查后按回车发送。助手给出 Issue 链接后，可从原生链接菜单选择「开始修复」。该入口用于 BW 界面。网页原型的批注操作见上一条。真壳验证范围见[贡献 BW 状态](../../05-features/bw-contribution/STATUS.md)。
- **查看改动。** 打开右栏的源代码管理。问号在工具栏右侧，文件筛选展开时也可使用。有改动时选择文件打开差异，引导随这次操作结束。列表为空且有改动时，先保存文件并清除筛选，再重新查看。

Windows Electron 已核对探索入口和样例的播放、暂停、续播、重播以及六段关键帧。隔离 Git 项目实走了源代码管理引导首次出现、跳过、重播、展开筛选与打开真实差异，以及浏览器帮助重播、添加批注、折叠和展开回看。动画使用模拟数据。真实使用时沿项目的验证约定和 GitHub 权限执行，适用的产品操作与未验范围见[探索状态](../../05-features/explore-workbench/STATUS.md)。
