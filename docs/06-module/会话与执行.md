# 会话与执行 — 模块实现心智

> **维护约定**：给修改开工、会话与工作树协作的人和模型读取；只写执行层的结构、边界与取舍，相关实现变化时更新。整体能力见 [architecture](../architecture.md) §2 ②；Orca 协议按需读 ref；不以旧 Rust 嵌入方式解释当前执行核。

## 实现心智模型

Workbench 直接叠在 Orca Electron 上，完整复用原生会话、标签/分屏、历史、资源管理器与工具。BW 只在右侧挂业务板：未开始时短卡提供“开始计划 / 开始验收”，实际原生运行会话打开成功后才展示四区；失败保留卡片并回显原因，空目标不阻碍板面展开。已有有效材料独立恢复，普通终端存在不证明流程启动。成功启动视图按流程、版本、项目/宿主/owner 和工作树隔离，仅保留于渲染进程以支持切屏，不另存业务会话绑定。配置自动化与会话收折沿页头和 Orca 原生入口。

已绑定流程树按真实绑定与宿主激活，旧无绑定流程沿固定树准备；无树版本只读回看已提交材料，浏览不建树。工作树可见性取原生登记与绑定，不等待会话恢复。所有树统一在原生右击菜单绑定、改绑或解绑，动作只作用当前树；解绑保留稳定身份、父子关系、文件、任务关联与会话。断链仅保留原生图标，点击不叠加 BW 提示、不清空目录或现有内容，其他导航继续可用；滚动沿原生侧栏。进屏不做 Git 同步，“更新代码”是唯一快进与材料重读入口，不能快进时保留现场与来源。文件问题随同一次手动运行作为上下文递交，助手说明方案后经人确认处理；不另建迁移会话、弹窗或贴草稿流程。

“开始计划／验收”调用对应已登记自动化的原生手动运行，启动前将该条目的工具保存为 BW 当前默认智能体，再使用已保存的提示、模型及会话复用配置，打开、聚焦本次原生会话；工具同步失败则回显错误并停止启动。该条目后续运行使用同步后的工具；定时运行仍在后台。普通原生新建会话不自动注入 BW Skill。首次登记默认关闭定时、使用固定工作区且 reuseSession=false，按 creationKey 去重；已有条目按当前 BW 版本覆盖同步 BW 所有的提示词（BW 持续演进，定时跑的必须始终是新版提示），人所有的设置（启用开关、触发时间、模型、会话复用）保留不覆盖；“配置自动化”打开原生编辑器。历史恢复和运行打开完全沿用 Orca。Tasks 往返沿原生导航历史，右侧筛选/滚动由 view-memory 保留。不存 BW 会话绑定或另建恢复流程。

计划屏与验收屏分别操作自己的固定树和材料。绑定树版本由绑定决定，旧无绑定树保留原生选版偏好。验收不以计划 PR 未合入或状态未知阻断会话；助手先提醒并协助处理，不自动合入。可保存的验收材料仍必须引用可读且身份一致的 committed 固定计划，无来源保持目标空白，不伪造 planRef。归档状态是事实读回，未知不装成已合入；阶段只供会话校准，界面不渲染灯。两屏纪要归档前核对每条已落实或有真实 Issue 跟进，交 PR 人审，不另设前端硬门禁。#439 本轮只有静态实现证据，真实会话、重启与跨宿主结果见各特性 STATUS；性能另窗处理。

## 主要矛盾与取舍

版本总览是只读入口：版本材料读端区分正式提交、工作稿和失败；历史验收沿 planRef 固定计划，回看截止取验收 PR 合入时间。特性读端复用任务源与 provider 路由，保留执行单到 PR 的关系；点击阶段横条打开对应的计划、设计、开发或交付来源，工作会话沿原生侧栏进入。BW 薄读取沿原生仓库授权、候选来源与并发限制投影 PR 正文和合入元数据，不加载原生评审文件、检查或合并策略；一次读取批次内按来源共用 PR/评论，避免目标内多个 Issue 重查同一 PR。目标内 workflow 报告使用 BW 薄 RPC 完整读取关联 PR 评论，失败传播为未知，首次后台读取与同范围内存缓存、独立刷新分开。总览不解析会话正文、不创建工作树或新增业务数据库；版本总览组合按来源限定的材料/特性请求、缓存与刷新通知；项目里程碑保持独立规划，不增加宏观行绑定。六阶段与历时解析为独立纯函数，缺失实际开工／独立测试时间保持空。行为与交付推导口径见[版本总览](../05-features/version-overview/spec.md)。

- **复用执行核**：终端、agent 生命周期、停止与切树由 Orca 管理；不要重新引入旧 Rust 的嵌页、配对 URL 与第二条开工 RPC。
- **上下文与材料一致**：两屏与会话经材料 RPC / `ORCA bw materials` CLI 操作同份版本材料；已有会话不会因文档更新自动获得新提示。
- **能力与可用证据分开**：工具安装、会话创建、模型读取规范、远端操作成功分别验证；缺文件或权限应报告实际原因，不假装已加载。
- **完成仍由人确认**：执行结束、PR 提交和用户验收是不同状态；旧自动化配置与全业务开工旅程随对应特性迁移验证。
