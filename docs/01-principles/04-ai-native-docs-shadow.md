# 04 影子笔记

本文件不是设计正本。正本是 [`04-ai-native-docs.md`](04-ai-native-docs.md)。这里只记写正本时用过的方法论约束，避免下次改文档时把过程概念写进设计空间。

- 角色先于路径。跨仓稳定的是「这份文档干什么」，本仓目录只是落点。不要在正本里解释「以前按编号目录思考、现在改成角色」。
- 对账是产品知识库已经在用的动作：契约和当前活跃特性对照实现。不要把现状写回愿景或契约来消差异。
- `docs/05-features/` 整棵树不是活跃集。活跃是 STATUS 过滤后的集合；已交付的约束吸收进契约。
- `AGENTS.md` 只放指针。正文按分支披露，避免每场会话都吞下 architecture 和全部 05-features。
- 本设计是对已有分层的视图建模，不是新开一套目录。01 仍管 gate 与仓根落点；04 管角色与加载协议。
- 用户点名的四块（愿景、架构、活跃特性、工程参考）是工程对账主路径上的四角；另外四条角色（产品帮助、对外 README、Agent 入口、项目约定）同样存在，不要为了「用户只点了四块」从角色表里删掉。
