Labels sit above the control at 11px/500; helper text below at 11px muted. Focus is the accent border plus a soft ring — errors surface the same way in --color-danger. No script anywhere: radios and the segmented control are native inputs. A select stays native too, minus the platform's own chrome — appearance: none and the house chevron, so it lines up with the fields beside it.

标签位于控件上方(11px/500),辅助文本在下方(11px 弱化)。焦点为强调色边框加柔和光圈,错误以 --color-danger 用同样方式呈现。全部为原生控件,无任何脚本。下拉框也是原生 select,只是把系统自带的那身外观(appearance: none)换成了本系统的折线箭头,好和旁边的输入框排在一条线上。
