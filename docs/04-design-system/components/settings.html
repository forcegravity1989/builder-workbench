One skeleton for every settings page: page head → sections → one bordered group per section → rows with the title and one sentence on the left and the control at the row end. Controls line up on one vertical line. Self-committing controls (toggle, seg, select) carry no Save; a free-text input that must not apply half-typed keeps a quiet Save beside it. The choice cards scope a data-theme so each preview shows its own palette.

所有设置页一个骨架:页标题 → 小节 → 每节一张描边分组 → 每行左边标题 + 一句说明、行尾一个控件。控件落在同一条竖线上。开关 / 分段 / 下拉自己生效,不配保存键;打一半不能生效的自由输入,旁边留一颗安静的「保存」。预览卡各自挂 data-theme,所以每张都显示自己那套配色。
