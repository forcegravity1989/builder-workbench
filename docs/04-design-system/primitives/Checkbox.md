# Checkbox

A 16px square, `radius` 4px; checked fills `primary` with a 14px check.

**Source:** `src/renderer/src/components/ui/checkbox.tsx` (Radix). Static rendition.

## Use
Independent on/off options inside a form that is saved together, and multi-select lists. For a setting that applies immediately, use Switch.

## The consumer provides
`checked` (`true` / `false` / `'indeterminate'` → minus icon), `onCheckedChange`, and a Label.
