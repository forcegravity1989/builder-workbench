# Label

The form label: 14px medium, line height 1, gap 8px to an inline control.

**Source:** `src/renderer/src/components/ui/label.tsx` (Radix Label). Static rendition.

## Use
Above a field inside the label group, or beside a Checkbox/Switch. Dims to 50% when its peer control or `data-disabled` group is disabled.

## The consumer provides
Text and `htmlFor` pointing at the control.
