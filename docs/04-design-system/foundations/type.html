Rules · 规则

One family — the system stack (--font-body, SF Pro on Apple hardware, Segoe UI on Windows) — with weight doing the hierarchy: 600 for headings and titles, 500 for buttons and row titles, 400 for body. Body carries letter-spacing: 0.01em globally. --font-mono marks the literal: IDs, branches, paths, counts, durations, keyboard keys. Don't add sizes between the steps — two values a pixel apart read as "the same, but wrong."

一个字族(系统字体栈)靠字重分层:标题 600、按钮与行标题 500、正文 400。正文全局 letter-spacing: 0.01em;等宽字体标记一切"字面值":ID、分支、路径、计数、时长、按键。不要在既有档位之间加新字号 — 相差一像素的两个字号读起来是"一样,但错了"。
