# Workbench Skills

> 给维护产品 Skill 的人和模型读；只列技能职责与读取入口，不承载 SOP 或更新流水。技能或分发职责变化时更新。修改前完整读取 [Skill 写作规范](SKILL-MD-SPEC.md)，源与完整包的分工见 [standard](../README.md)。

| Skill                                             | 用户结果                                       | 入口     |
| ------------------------------------------------- | ---------------------------------------------- | -------- |
| [week-planning](week-planning/SKILL.md)           | 形成有依据的版本目标，关联真实任务并归档计划   | 计划屏   |
| [version-acceptance](version-acceptance/SKILL.md) | 准备会议与证据，记录人的结论，归档并按授权发布 | 验收屏   |
| [metrics-refresh](metrics-refresh/SKILL.md)       | 明确用途与来源，准备并实跑历史采集能力         | 配置指标 |

三个入口使用完整 Skill 文件包，公共规则源在 `../references/`。项目开发、评审与交付遵循项目自己的 AGENTS，不由业务 Skill 改写。
