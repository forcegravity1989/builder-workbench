# 验收证据聚合

> 验收会话收到聚合请求后完整读取。本文规定证据提取、待核对事项及报告登记；旅程在 SKILL.md，呈现槽位在报告模板。生成规则或登记接口变化时维护。

## 读取现成证据

从固定计划读取目标与验收标准，按 `bw:plan:<版本>` 查询真实 Issue，并用标题中匹配本版的目标段归类。把未归类成员和读取失败列入报告。读取项目约定和各 Issue/PR/MR 已留下的验证产物。有实现交付的任务核对实现 PR/MR 与验证报告；无开发直接关闭的任务核对 Issue 评论中的处理依据。不假定用户项目采用 BW 的研发 Skill 或报告文件名。

验收只聚合，不重新跑开发验证、不反推期望结果或执行路径。来源可以是截图、日志、读数、CI/流水线、逐条用例结果、修前修后对跑、平台读回或 DOM 断言；判据是人能独立核对事实，不限图片。提交、PR 合入、测试通过与真实用户旅程分别说明，不互相替代。

## 提取与呈现

- 每个目标保留固定计划中的验收判据原文；每个 Issue 先用一句话说明兑现哪条承诺、怎么验、看哪里。这是归并说明，不当作验证证据。
- 基本用例逐条成表：用例名、期望、实际结果、证据形态与来源、执行路径或原文链接；开发侧未留的字段如实写未留，不压成一段转述。
- 组合、异常、负例与完整门禁细节点名原验证报告链接；每个 Issue 保留门禁实数与未验范围。命令全文、排查及独立检视过程只留来源链接。
- 截图就地内嵌并保留原图链接、固定提交和文件名；只有本地图片时放报告同目录的 `shots/`。提交、Issue、PR/MR、流水线与图片地址沿实际平台已读回的 URL，不用仓库名拼另一平台地址。链接缺失如实标注，不能补造。
- 无截图先判断证据形态：命令、配置、数据或接口类改动可提取 PR/MR 已有的其他证据；证据不足、漏截图或开发侧自述未验的列为待核对，不一律放过或当成验证通过。

报告中的文本及 HTML 属性值须正确转义；链接不可读、证据对应原问题还是修复结果不明时，保留来源及待核对说明。报告与演示环境不一致时提醒人核对候选。

## 待核对与人工结论

待核对项使用稳定编号，说明证据现状、已有其他形式证据及可选处置：PR/MR 补充后重新聚合、人在本次会话提供补充、会上实机演示。**待核对不阻塞报告生成、登记和打开，也不代表验收通过。**

人确认后的缺口按三类呈现：需要实现交付却已关闭无合入件、尚未合入、无读数或不可核对。无开发关闭项先查 Issue 处理依据，不要求虚构 PR。人未回应的事项继续保持待核对，不替人决定处置或验收结论。

人一次回应多条时按编号分别回填；只修改一条时保留其他已定项。处置为会上演示时保留该安排，不能记为演示通过。补充证据后更新对应条目；人已核对通过但未留实物的，记录谁、何时、核对什么，不改写成自动验证通过。

## 生成、登记与继续核对

1. 完整读取[报告模板](../assets/evidence-report-template.html)。在候选固定后，生成一个版本一份的 HTML 报告，保存到 `.bw/planning/<版本>/acceptance-evidence.html`；本地图片放同目录 `shots/`。报告与项目发布总结各有职责，不互相替代。
2. 自检模板占位已替换、基本用例可核对、来源与未验范围明确；待核对项有编号和事实说明，未获人确认的结论没有写成通过或已处置。
3. 使用开工读回的项目、工作树和宿主身份立即登记，不等待待核对项逐一处置：

   ```bash
   ORCA bw materials add-artifact --repo-id <id> --worktree-id <id> --host-id <host> --workflow acceptance --version <版本> --kind verification --location .bw/planning/<版本>/acceptance-evidence.html
   ```

   命令在工作树所属宿主完成读改存：文件必须存在；`mtime` 作 `generatedAt`，复用材料现有 `candidateRef`，同 artifactId 更新；修订冲突自动重读重试一次。候选未固定或保存失败先处理原错误，不直接改材料文件绕过服务。可按实际结果提供 `--artifact-id`、`--command`、`--checksum`；参数与材料边界见已完整读取的[版本材料](../../../references/version-records.md)。

4. 读回制品引用，告知报告位置和待核对项。板面约五秒刷新并提供打开入口；未亲见板面时不声称界面已亮。
5. 向人呈现编号清单并继续核对。收到处置或补充后修改同一份报告，重新登记、读回；未回应的项继续保留。登记只让报告可查看，不写入人的目标结论，不自动关闭 Issue。
