# 验收会议预订

协助会议助手完成一件事：**为某个 BW 版本预订 WeLink 验收会议，并把会议信息写回该版本的验收材料**。全程在会话中与人对话完成：先核对这台机器上的项目、版本、验收工作树和材料写权限，再生成完整预览，经人确认后建会、读回、写回，每步完成打一行回执。本技能只管会议；验收屏的出包、部署、Showcase、纪要、归档与发版由 version-acceptance 技能承接，两边同期并存、互不替代。向项目群发会议通知、写纪要草稿是后续阶段，本技能不做。

## 开工与恢复

1. 完整读取[公共执行规范](../../references/execution.md)与当前项目 AGENTS.md，按其中的方法核对 CLI、身份与当前原生工作树。会话工作目录是 bot 主目录、不在任何工作树内：人给出版本并确认后，按规范里的方法从 `worktree list` 找版本绑定为该版本验收的工作树读回身份，找不到或多个匹配交人指认，不猜。
2. 完整读取[版本材料规范](../../references/version-records.md)。从读回的工作树取项目、工作树和宿主身份填写命令参数，再执行 `ORCA bw materials context --repo-id <id> --worktree-id <id> --host-id <host> --workflow acceptance --json` 核对工作区绑定的版本；用 `list` 读取材料候选。
3. 入口提到的版本须与工作区绑定一致；查不到有效绑定、版本不符或材料不可写时，停止业务操作并说明补救办法，请人指认正确的验收工作树或换有写权限的宿主。不另建工作树。

## 预订会议

收到预订、改期或取消请求后，完整读取[会议预订](references/meeting-preparation.md)，按其中的步骤执行：材料预检 → `welink-cli auth status` → 定与会人 → 定时间 → 完整预览经人确认 → 创建会议 → `meeting info` 读回 → 只把会议信息合并写回材料 `meeting` 字段。

- 缺 `welink-cli`、登录失效、材料只读或版本未绑定时，如实说明补救办法并在建会前停止，不绕道、不降级。
- 已有会议不重复订：先读材料 `meeting` 并用 `meeting info` 核对，指向同一会议再继续。
- 写回失败时先把会议 ID 与链接告诉人，再读最新修订重写**同一会议**；创建结果未知先用 WeLink 核实，不盲目重建。
- 改期、取消由人说明，同样先预览再执行，并同步材料 `meeting`。

## 边界

- 只预订、改期、取消**该版本的验收会议**，只合并写回材料 `meeting` 字段；其余字段（含人工结论）原样保留。
- 不做出包、部署、Showcase、纪要、归档、发版；不向项目群发消息、不写纪要草稿。
- 每次外部写入（建会、改期、取消、材料保存）前都有完整预览与人的确认；预览有变化原确认失效。
