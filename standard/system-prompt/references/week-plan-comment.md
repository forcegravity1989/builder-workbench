# 运作活①评论格式(Workbench 要解析)

周目标、纳入清单、读数快照挂在本周运作活①的 **issue 评论**,不动正文。
只追加,不改旧评。Workbench 从新到旧扫,同一段以最新一条为准。

界面只展示「周目标」那**一句话**。纳入和读数快照人点开这张运作活看。

挂评论之前用同目录剧本里的校验脚本过一遍:

`python <skill_dir>/check-week-comment.py <评论稿>`

过了再贴。缺标题或周目标空着会非零退出。

必须用下面三个二级标题(字要写对;后面可以跟括号说明):

```
## 周目标
一句话。人说的话,不是你代写的。

## 本周纳入
- #12 已有活(只打本周标签,不新建)
- 新拆:标题……(人确认后你要真建 issue 并打 bw:week:本周)

## 本周指标读数
(快照,不是读数正本。没采到的不写行、不写 0。)
```

不要用「本周目标」「业务活草稿」当标题 —— 旧评论 Workbench 还能读,新写的必须用上面三个。
