# 校准参考

定级会随会话漂移：同一个仓，这次判 2、下次判 3。防漂移的办法是先看已经定过级的仓在同一条上是什么读数，再判手上这个。

**这份表是数据，不是判据。** 判据永远是 [`rubric.md`](rubric.md) 的「3 分的样子」列。这里只回答「别人到这个数的时候被判了几分」。

## 怎么用

1. 定级前，找同一条目在下表里的读数区间。
2. 手上这个仓的读数明显高于「成熟层」却想判 2，或明显低于「成文层」却想判 3——停下来，先解释为什么。
3. 扫完一个仓后把它的读数追加进来（尤其是判 0 和判 3 的条目），表越厚，尺越稳。

## 怎么追加

一行一个仓，只记**通用读数**（带方言的读数不可跨仓比，不进这张表）。仓名可以匿名化成 `<生态>-<规模>-<日期>`，重要的是读数和定级，不是它叫什么。

## 两个参考仓之间的差距在哪

不是「有没有做」，而是**最后一跳**：R2 的多数纪律停在「成文」，R1 把同样的纪律变成了「机器强制」。给新仓定级时，这一跳就是 2 与 3 的分界——问一句「违反了会不会红」，比问「写没写」更能定准。
