# 静态扫描与 HTML 全景

> 30 秒导读：扫描用于发现知识形态、结构提示与引用问题。源文件仍是正本；HTML/JSON 可重新生成。字段存在与链接存在均不证明语义正确或已验收。

## 运行

需要 Node.js，无第三方运行依赖。BW 的映射放在 [bw-scan.json](projects/bw-scan.json)，包含范围、文档类型和候选结构提示；其他项目复制并调整映射，不能直接继承 BW 目录。

`include` 是可能存在的文件/目录清单，不是规范要求。不存在的候选路径会显示为 `selected-path-missing`；不恢复已退役文件，也不能据此判为本轮缺失交付。脚本自身的确定性测试已接入 BW 交付验证；全库扫描结果尚未作为 CI 门禁。

```text
node <Skill>/scripts/scan-knowledge.mjs --root <目标仓> --profile <Skill>/references/projects/bw-scan.json --out <仓外报告目录>
```

输出固定为 `knowledge.json` 与 `knowledge.html`。输出目录必须在目标仓之外，避免扫描器覆写源文件或把生成物当新知识。只有本次指定输出会被更新，无远端写入。

整改前保存一次输出；整改后用新的输出目录，并传 `--baseline <前次 knowledge.json>`。同仓、同映射的指纹变化仅表示内容变动，不自动表示完成治理。规则映射变了会说明不可直接比较；不静默比较不同口径。

## 分清五种结果

| 结果 | 从什么计算 | 限制 |
|---|---|---|
| 文件与职责 | 指定路径、扩展名、显式类型映射 | 未识别项保留为未分类；不是特性全集 |
| 引用关系 | 已支持的 Markdown 文件链接/导入，反向计数 | HTML/源码/外链读取方不在此图中；无入链不证明无用 |
| 结构提示 | 标题与段落中是否识别到候选内容字段、长段落 | 候选规则不是已采纳门禁；没识别可能是写法不同，识别到不等于正确 |
| 内容对象 | CHANGELOG 的二级分组和段落长度；采用指定表头的验收映射行 | 只能统计已映射结构，不将未知数据记成零特性/零验收 |
| 候选债务 | 缺文件引用、完全重复的长段落、待核对结构、扫描范围内无入链 | 人核对后决定处置；不自动删档/改规则 |

映射 JSON 是可执行检查配置，`contractSource` 指回其人读规范。内容契约变动时一起修改和验证；它不是第二份项目业务正本。当前 BW 映射是试验候选，尚未在全仓采纳，结构提示仅供整改选择。

## 用于看护

当前顺序：**先逐篇整改与反哺内容规范，再稳定检查口径，最后集中改进人看的全景页。** 当前页面只供试用，不据此冻结知识库结构。

| 阶段 | 先稳定什么 | 允许怎样变化 |
|---|---|---|
| 逐篇试验 | 本轮文档职责、必要内容、旧债去向 | 真实整改发现规范不合适，先改规范，再更新该类型映射和案例；页面可保持朴素 |
| 类型规范采纳 | 人读契约、机器可检查的字段/关系、误报边界 | 同类型旧文档已按本轮采纳范围清理，正反案例通过，才将可靠检查接入看护 |
| 全景呈现收敛 | 有版本的 JSON 输出及稳定解释 | 再按人的查找、决策、维护任务重做页面；主要改视图，不另算一套事实 |

一次规范变更的联动单位是：**规范原件 → 映射/解析规则 → 正反案例 → 输出口径/版本 → 必要视图**。只改提示文字或网页标签不能替代规则升级。修改输出字段含义时升级扫描器/schema 版本；修改类型映射时升级映射版本并保留指纹。前后口径不同就重建基线，不直接比较。

规范稳定后脚本可作为稳定工具维护，但不是永远不变；只因真实缺陷、规范修订或新类型需要而更新。全景 UI 优化不必拖住逐篇清债。

- 现在：每轮前后手动运行，打开静态 HTML；查看文件目录、筛选、详情、链接问题、重复段落候选及变更对照。
- 试跑后：本地检查或 CI 可以运行同一脚本。`--check` 仅对文件读取/明确缺失引用等机械错误返回非零；候选结构提示不拦截旧库。
- 正式收紧：每类规范认可并整改其存量、检查误报被验证后，再单独启用该类内容门禁。保留尚未覆盖的范围和规则版本。
- 周期运行：尚未创建自动化任务；需要在已有自动化/CI 中明确频率、产物位置与异常处理后再启用。

扫描页面不会推断 PR 是否合入，也不会把文件日期推断成治理日期。治理完成与 Skill 反哺状态来自真实任务交接记录；未接入时明确显示未提供。

## 安全与适用边界

只遍历映射中选定目录，不跟随符号链接；默认排除 .git、node_modules、target 和工作树目录。Markdown 只做有限语法识别，HTML/TOML 只列资产，不宣称检查正文。外链/标题锚点未核验；旧文档中已失效引用可能是历史事实，报告保留上下文供判断。

HTML 对仓内容转义，数据嵌入不执行源文件的脚本。阅读文件链接不代表运行目标。扫描不执行构建、采集器或 E2E；没有生成价值分数或“全库健康绿灯”。
