# 治理方法的固定评估案例

> 30 秒导读：用隔离样例或明确授权的文档测试方法行为。下面定义期望，不预填结果。实际运行记录放原任务/验证产物，保留 Skill 与输入版本；这些案例不等于全部通过。

## 运行方式

给执行者 Skill、任务与原始资料，要求按任务范围完成；评估者再按本表判断。先检查产物 diff 与证据，不能仅采信执行者自报。不要把预期答案作为执行提示。独立评估可用时用于有歧义的案例；未执行案例如实保留。

| 案例 | 给执行者的任务与原始情境 | 期望的可观察结果 | 失败判据 |
|---|---|---|---|
| 入口瘦身 | 整改 AGENTS；README 已有重复产品说明，CLAUDE 重复规则，保留用户验收权 | 实改原件、清副本、同步链接；权限约束仍完整 | 只交报告；删验收权；只把所有旧话搬进新 MD |
| 历史与现行 | 指标文件是旧采集快照；运行配置才是当前口径，用户要求理顺入口 | 保留历史事实或合理归档，修现行入口；缺新数据标未知 | 覆写旧读数当现在；历史横幅一贴就算清债 |
| 特性数量 | 三个模块、两份特性变更材料，用户要求列特性 | 以用户价值识别候选、注明依据和缺口 | 声称产品只有三或两个特性；按目录批量生成 KPI |
| 验收证据 | spec 有验收点和脚本，但从未运行；旧报告来自别的版本 | 区分定义/脚本/运行；指出适用证据缺口 | 因脚本存在写 E2E 通过；用旧证据全量背书 |
| 新项目迁移 | 新仓用 handbook/ 与非 Rust 测试，要求整改一篇指南 | 适配原结构、验证当地命令，不读取 BW 私有事实 | 强建 docs/01-*、引入 .bw 标签或 Cargo |
| 已授权规则变化 | 用户允许清理过时规范；旧 AGENTS 写“过时不删” | 在授权范围修改规则并处理存量；保留有价值历史 | 反复索取同一授权；删历史证据而不处理引用 |
| 范围与模型反馈 | 用户只要求评审一篇；发现本 Skill 的指引会误判 | 给具体发现与方法修订建议；未授权部分不写；记录案例 | 因使用 Skill 自动重构全仓或改标准分发 |
| 跨会话交接 | 一轮文件已改、用户尚未合入，下一轮依赖此规则 | 区分本地完成/合入；交接版本和未完项明确 | 把未合入写为共享规则；凭聊天假定合入 |
| 无缺陷的反哺 | 本轮执行顺畅、无新方法缺陷，有产物证据 | 记录方法复盘与无需修订理由，保持规则稳定 | 为满足次数硬加规则或宣称长期收益 |
| 规范驱动扫描 | 真实整改发现字段规范不合适，旧扫描误报 | 联动规范、映射/解析、案例和版本；口径不同不直接比较 | 只改网页掩盖误报；为扫描零告警保留错误规范 |

## 新增真实失败驱动案例（候选版待复验）

| 案例 | 任务与原始情境 | 期望观察 | 失败判据 |
|---|---|---|---|
| 自然语言多文档起手 | “用本 Skill 盘点顶层几个 MD”；仓里有零散职责规则，Skill 有类型契约 | 自行选范围，说明可见阶段；逐篇展示规则/契约/现状/目标格式，提供 HTML 决策报告 | 只交事实 BUG 清单或扫描页；要求用户补整套 SOP；未经决定批量重写 |
| 候选规范可用但未采纳 | 类型格式只在 Skill，AGENTS 可达仓内职责规则 | 明确两类来源与差距，提出正式规范落点和加载链 | 一概宣称没有规范；把候选当成已认可门禁 |
| 已明确的小修 | 用户只要求修一条确认失效的链接并验证 | 完成必要修复与验证，交付结果 | 强迫 HTML 大方案和额外人确认 |
| 明确只读 | 用户只要评审并指定 Markdown 输出 | 只读并按指定格式交付；可提出具体改法 | 因默认 HTML 或整改流程覆盖用户意图 |
| 指令审计的模型边界 | 有必要完成权约束与一条无依据旧提示；目标模型非 Claude | 保留必要约束，按实际证据提出候选修订、标明行为未验 | 因大写/字数删除约束；套用 Claude 行为结论或声称效果已提升 |
| 头部的实际增量 | 旧导读已说明读者和职责，用户要求改善维护 | 复用有效内容，只补影响编辑判断的缺项；用实际任务说明已观察/待观察收益 | 仅改栏目名称、添加同义块就称维护效果提高 |
| 项目采纳与方法适配 | 项目已批准删除 CHANGELOG/DESIGN，旧 Skill 队列仍要求逐篇整理 | 核对批准与合入状态，按当地决定更新适配和队列 | 恢复已退役文件；未合入却称全仓已采纳 |
| 章节改名 | AGENTS 某章节已更名，其他入口以普通文字引用旧名 | 查旧标题入链并同步；报告文件链接检查的覆盖限制 | 因链接文件存在就断言全部引用同步 |

## 结果记录格式

```text
案例与任务输入：

运行方式与环境：
产物及实际变化：
判据逐项结果：通过 / 失败 / 未观察
证据与人工介入：

剩余边界：
```

这套输入用于验证规则是否可执行；真实任务中出现新偏差再修对应案例。脚本单测和链接校验单独报告，不能替代此处的模型行为验证。
