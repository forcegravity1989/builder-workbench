## Issue #编号 · 主验证报告

**结论：** 通过 / 未通过 / 未复现 / 未验证。说明是否具备交付条件及关键未验范围。

**最终变化：** 用户问题、恢复或新增的行为、主要选择及依据；技术细节放下方。

**对照版本：** 基线 SHA / 认可原型或 spec 版本 → 当前实现 SHA。仓外 plan：可定位的版本或记录，无则说明适用范围。

**用例与判据：** 用例名；必要数据/配置；入口 → 操作 → 观察位置；预期的具体结果。多用例只展开影响结论的对照，其余证据链接放折叠部分。

| 修复前 / 已认可原型与规格 | 修复后 / 实际落地 |
|---|---|
| 实际失败或认可判据；界面证据内嵌钉 SHA 图片 | 实际结果与对应证据；差异及认可来源 |

**独立检视：** 检视输入版本、覆盖的六项及不适用项依据；测试 agent 的独立复验范围。静态判断与实际运行分开。

| 发现与影响 | 处置及位置 | 复核结果 |
|---|---|---|
| 具体问题、判据或差异 | 修正 / 已认可范围调整 / 阻塞未验及依据 | 谁按哪个版本复核、结果与证据 |
