# loop/ — 自主交付编排的外部参考

> **读者与时机**：研究 workflow/loop 的人和模型按需读取，不属于 BW 日常开工必读路径。
>
> **职责与维护**：本篇导航外部审计框架、实例和方法，说明来源与使用边界；不承载 BW 的执行规范、实施计划或缺口台账。来源、文件或适用范围变化时同步本篇与引用。BW 当前要求由 [AGENTS](../../../../../AGENTS.md) 和[开发交付细则](../delivery-contract.md)维护。

| 文件 | 内容与用途 |
|---|---|
| [workflow-audit](workflow-audit/SKILL.md) | 外部审计框架原文；研究编排、工具、评估与反哺判据时参考 |

原文中的 fixer、loop-buddy 是来源项目名；来源自身的规范、完成度和待办不能直接当作 BW 要求。镜像保持来源格式，方法提炼与项目采用分开；BW 只将实际采纳的稳定决定写回对应正本，不从外部框架推导额外审批或新建一套资产。

这些材料不证明 BW 已具备相应自动化能力。研究具体方案时先核对当前代码、Orca 原生能力和已认可规格；实现计划留在仓外任务产物，旧方案与调查过程从 Git 或原 PR 追溯。
